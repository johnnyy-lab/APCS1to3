Q-11-01-R01定義之後，呼叫才會執行 運行追蹤

對應 單元 11.1

下列 Python 程式執行後，畫面上印出的結果為何？

def show(n):
    print("A", n, end=" ")

print("S", end=" ")
show(2)
print("M", end=" ")
show(5)
🎉 答對了！標準答案是 (C)
⚡ 速解

def 只登記不執行。主程式從上往下，碰到 show(2) 就進去印 A 2，印完回來繼續，第二次 n 換成 5，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • def show(n) 那三行只是把名字 show 記起來，這時什麼都沒印。
  • 先印 S。接著 show(2)：n 是 2，印 A 2。
  • 回到主程式，印 M。再 show(5)：n 是 5，印 A 5。
  • 全部接起來是 S A 2 M A 5。故選 (C)。
  1. 選項逐項診斷：
  • (A) 以為函式一定義就先跑完。def 那幾行只是登記，不會印任何東西。
  • (B) 以為呼叫會被延到最後再一起執行。呼叫一碰到就立刻進去執行。
  • (C) 從上往下走。def 只登記名字，遇到 show(2) 才進去印，印完回到下一行，順序正確。
  • (D) 以為參數會記住第一次的值。每次呼叫都用新的引數，第二次 n 是 5。
  1. APCS 考場心法與常見陷阱：
  • 函式內的程式只在被呼叫時才跑，而且是每呼叫一次就跑一次。
  • 呼叫結束後，控制權回到呼叫那一行的下一行。每一次呼叫的參數都是重新接收的引數。

Q-11-01-R02引數先算好再交給參數 運行追蹤

對應 單元 11.1

下列 Python 程式執行後，畫面上印出的結果為何？

def step(k):
    print("in", k, end=" ")

print("go", end=" ")
x = 3
step(x + 1)
step(x)
print(x)
🎉 答對了！標準答案是 (A)
⚡ 速解

step(x + 1) 傳的是 4，step(x) 傳的是 3，x 全程沒被指定新值，最後仍印 3，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 先印 go。x = 3。
  • step(x + 1)：先算 x + 1 得 4，交給參數 k，印 in 4。
  • step(x)：k 這次是 3，印 in 3。
  • 最後 print(x) 印 x，沒人改過它，仍是 3。故選 (A)。
  1. 選項逐項診斷：
  • (A) x + 1 先算成 4 交給 k，x 自己沒變。第二次傳 x，k 是 3。最後印出的 x 還是 3。
  • (B) 以為 k 會留著上一次的 4。每次呼叫 k 都重新綁定。
  • (C) 漏看第一次呼叫傳的是 x + 1，把它當成 x。
  • (D) 以為 step(x + 1) 會讓 x 變成 4。函式呼叫的引數只是算出一個值，不會改到 x。
  1. APCS 考場心法與常見陷阱：
  • 呼叫時括號裡可以是任何算式，Python 先算出值再交給參數。
  • 參數 k 是函式裡面的名字，改它不會動到外面的 x。這題連改都沒改。

對應 單元 11.1

預期印出 x=2 y=7。空格應填入哪一個？

______
    print("x=" + str(a), "y=" + str(b))

pair(2, 7)
🎉 答對了！標準答案是 (D)
⚡ 速解

呼叫給兩個引數，標頭就要有兩個參數，而且 def 與冒號缺一不可。四個選項只有 (D) 全齊，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 函式標頭的寫法是 def 名字(參數們):。
  • 呼叫是 pair(2, 7)，兩個引數，所以參數要兩個：a 與 b。
  • 函式本體有縮排，標頭一定要以冒號結尾。
  • 符合的只有 def pair(a, b):。故選 (D)。

  1. APCS 考場心法與常見陷阱：
  • 引數與參數的個數要一樣多。差一個就是 TypeError，錯誤訊息會直接告訴你收到幾個。
  • 看到標頭少了 def 或少了冒號，都屬於語法錯誤，程式一行都不會跑。

Q-11-01-F02呼叫時交出什麼引數 程式填空

對應 單元 11.1

預期印出 ###。空格應填入哪一個？

def row(n):
    print("#" * n)

row(______)
🎉 答對了！標準答案是 (B)
⚡ 速解

n 要是整數 3。只有 1 + 2 算出整數 3，其他不是字串、不是兩個引數，就是不存在的名字，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 函式內是 "#" * n，要印 ###，n 必須是整數 3。
  • "3" 是字串，字串不能乘字串，會 TypeError。
  • 3, 3 是兩個引數，row 只有一個參數，也會 TypeError。
  • n 是函式裡面才有的名字，主程式用它會 NameError。
  • 1 + 2 先算成 3，傳進去剛好。故選 (B)。
  1. 選項逐項診斷：
  • (A) 傳進去的是字串 "3"。"#" * "3" 丟出 TypeError: can't multiply sequence by non-int of type 'str'。
  • (B) 括號裡先算出 3，交給 n。"#" * 3 印出 ###。
  • (C) 給了兩個引數，函式只收一個，丟出 TypeError: row() takes 1 positional argument but 2 were given。
  • (D) n 只存在函式裡面。主程式這裡沒有 n，丟出 NameError: name 'n' is not defined。
  1. APCS 考場心法與常見陷阱：
  • 引數可以是算式。括號裡先算出值，再一個一個對應到參數。
  • 參數名稱只在函式裡面有效。主程式呼叫時要自己準備好值。

Q-11-01-D01呼叫跑在定義前面 測試除錯

對應 單元 11.1

想印出 start 再印出 hi。現在印出 start 之後就停住，錯誤是 NameError: name 'greet' is not defined。只改一處，哪一個改法會印出預期結果？

print("start")
greet()

def greet():
    print("hi")
🎉 答對了！標準答案是 (A)
⚡ 速解

Python 從上往下走，greet() 跑的時候下面的 def 還沒被讀到。把呼叫移到 def 後面，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 現況：先印 start，接著執行 greet()。這時 def greet(): 還沒被讀到，名字不存在，丟出 NameError。
  • 解法的重點是「先定義，後呼叫」。
  • 移動呼叫那一行到 def 之後，名字登記完才呼叫，能執行。
  • 故選 (A)。
  1. 選項逐項診斷：
  • (A) 移到 def 之後，名字已經登記，呼叫成功。start 先印，再印 hi。
  • (B) 拿掉 def 就不是函式定義，變成語法錯誤，連 start 都印不出來。
  • (C) 沒有括號只是提到名字，而且這時名字還沒登記，仍然是 NameError。
  • (D) 名字有了，但值是 None。greet() 變成呼叫 None，丟出 TypeError: 'NoneType' object is not callable。
  1. APCS 考場心法與常見陷阱：
  • 定義與呼叫是兩個階段。def 讀過一次，名字才存在。
  • 函式本體裡面如果呼叫別的函式，只要在「真的執行」之前定義好就行。主程式的呼叫則一定要排在定義之後。

hello

Q-11-01-P01函式本體跑了幾次 效能分析

對應 單元 11.1

下列程式執行時，print("b", end="") 這一行共執行幾次？

def beep():
    print("b", end="")

for i in range(3):
    beep()
    beep()
beep()
🎉 答對了！標準答案是 (B)
⚡ 速解

函式本體每被呼叫一次就跑一次。迴圈 3 圈 × 每圈 2 次，再加外面 1 次，共 7 次，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • def 本身不印。只有 beep() 被呼叫，裡面那行 print 才會執行。
  • 迴圈執行 3 圈，每圈有 2 個 beep()，共 6 次。
  • 迴圈結束後，最後還有一個 beep()，再加 1 次。
  • 6 + 1 = 7。故選 (B)。
  1. 選項逐項診斷：
  • (A) 漏掉迴圈外面最後那一次 beep()。
  • (B) 迴圈 3 圈，每圈呼叫 2 次，共 6 次。迴圈外再呼叫 1 次。6 + 1 = 7。
  • (C) 只數了迴圈圈數。每圈裡呼叫了兩次，不是一次。
  • (D) 以為函式只寫了一行 print，所以只執行一次。寫一次不等於只執行一次。
  1. APCS 考場心法與常見陷阱：
  • 數函式本體的次數，就是數「呼叫」的次數，包含在迴圈裡面的與迴圈外面的。
  • 程式碼寫了幾行與執行幾次是兩回事。迴圈與函式呼叫都會讓同一行跑很多次。

Q-11-01-P02函式裡的迴圈加上外面的呼叫 效能分析

對應 單元 11.1

下列程式執行時，print("*", end="") 這一行共執行幾次？

def line(n):
    for i in range(n):
        print("*", end="")

for k in range(1, 4):
    line(k)
line(2)
🎉 答對了！標準答案是 (C)
⚡ 速解

每次呼叫 line(n) 就印 n 次。傳進去的依序是 1、2、3、2，加起來 8，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 外層 k 依序是 1、2、3，各呼叫一次 line(k)。
  • line(1) 印 1 次，line(2) 印 2 次，line(3) 印 3 次，共 6 次。
  • 迴圈結束後還有一個 line(2)，再印 2 次。
  • 6 + 2 = 8。故選 (C)。
  1. 選項逐項診斷：
  • (A) 這是 line 被呼叫的次數（3 次迴圈加最後 1 次）。每次呼叫裡面還有自己的迴圈。
  • (B) 只算了 line(1)、line(2)、line(3) 的總和 1 + 2 + 3，漏掉最後一行的 line(2)。
  • (C) line(1) 印 1 次，line(2) 印 2 次，line(3) 印 3 次，最後 line(2) 再印 2 次。1 + 2 + 3 + 2 = 8。
  • (D) 以為每次呼叫都轉 3 圈。n 是每次呼叫傳進來的值，會變。
  1. APCS 考場心法與常見陷阱：
  • 函式裡有迴圈時，每次呼叫的次數取決於那一次傳進來的引數，要逐次相加。
  • 不要漏看迴圈外面的呼叫。

Q-11-01-L01f(n) 在算什麼 計算邏輯

對應 單元 11.1

下列程式印出 10 55。哪一句描述 f(n) 印出什麼，換成其他正整數 n 也成立？

def f(n):
    s = 0
    for i in range(1, n + 1):
        s += i
    print(s, end=" ")

f(4)
f(10)
🎉 答對了！標準答案是 (B)
⚡ 速解

迴圈從 1 加到 n，是 1 + 2 + … + n。4 得 10，10 得 55，20 得 210，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • s 從 0 開始。迴圈 i 走 1 到 n，每圈 s += i，所以是 1 加到 n 的總和。
  • f(4)：1 + 2 + 3 + 4 = 10。f(10)：1 + … + 10 = 55。
  • 換成 n = 20：20 × 21 ÷ 2 = 210。
  • 只有一個選項的算法同時是 10、55，也能推到 210。故選 (B)。
  1. 選項逐項診斷：
  • (A) f(4) 恰好 10，但 f(10) 應是 16，不是 55。
  • (B) 迴圈把 1 到 n 全部加起來。f(4) 是 10，f(10) 是 55，f(20) 是 210。
  • (C) f(4) 恰好 10，但 f(10) 應是 22，不是 55。
  • (D) f(4) 恰好 10，但 f(10) 應是 94，不是 55。
  1. APCS 考場心法與常見陷阱：
  • 判斷函式在算什麼，先看函式本體，不要只盯著幾組輸出。其他選項可能剛好對上第一組數。
  • 1 到 n 的總和可以用 n * (n + 1) // 2 檢查。

Q-11-01-L02位置引數的先後 計算邏輯

對應 單元 11.1

下列程式印出 34 43。哪一句描述 mix(a, b) 印出什麼，換成其他 0 到 9 的引數也成立？

def mix(a, b):
    print(a * 10 + b, end=" ")

mix(3, 4)
mix(4, 3)
🎉 答對了！標準答案是 (C)
⚡ 速解

第一個引數對應 a，乘 10 排十位；第二個對應 b，排個位。mix(5, 0) 是 50，mix(0, 7) 是 7，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 呼叫 mix(3, 4)：由左而右，a 是 3，b 是 4，3 * 10 + 4 = 34。
  • 呼叫 mix(4, 3)：a 是 4，b 是 3，結果是 43。位置一換，結果不同。
  • 推到其他引數：mix(5, 0) 是 50，mix(0, 7) 是 0 + 7 = 7。
  • 故選 (C)。
  1. 選項逐項診斷：
  • (A) 數字相乘再相加，結果是整數，不會印出前導的 0。mix(0, 7) 印出 7。
  • (B) 把順序弄反了。mix(3, 4) 會印出 43，與題目第一個輸出 34 不符。
  • (C) 第一個引數對應 a，在十位。mix(5, 0) 是 50，mix(0, 7) 是 7。
  • (D) mix(3, 4) 若是 a + b 會印出 7，與題目第一個輸出 34 不符。
  1. APCS 考場心法與常見陷阱：
  • 位置引數是由左而右一對一配對的。順序換了，各個參數接到的值也跟著換。
  • a * 10 + b 是把兩個一位數組成兩位數的典型寫法，但結果是數字，不會帶前導 0。

## 單元 11.2 函數回傳值與衛語句

Q-11-02-R01return 之後的程式不會跑 運行追蹤

對應 單元 11.2

下列 Python 程式執行後，畫面上印出的結果為何？

def add(a, b):
    return a + b
    print("done")

x = add(2, 3)
print(x, add(x, 1))
🎉 答對了！標準答案是 (B)
⚡ 速解

return a + b 一碰到就結束，後面的 print 不會跑。x 是 5，再呼叫一次 add(5, 1) 是 6，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • x = add(2, 3)：函式算出 2 + 3 = 5，return 把 5 交出來，函式立刻結束。print("done") 沒被執行。
  • x 現在是 5。
  • print(x, add(x, 1))：x 是 5。add(5, 1) 回傳 6。
  • 印出 5 6。故選 (B)。
  1. 選項逐項診斷：
  • (A) 以為 return 後面的 print 還會執行。函式碰到 return 就結束並交出值，後面的行不會跑。
  • (B) add(2, 3) 回傳 5，存進 x。add(5, 1) 回傳 6。return 後面的 print("done") 永遠沒機會執行。
  • (C) 以為第二次呼叫還是用 2 和 3。add(x, 1) 用的是 x 的 5 和 1。
  • (D) 以為 return 沒有把值交出來。有 return 的函式，呼叫的位置就是它交出的值。
  1. APCS 考場心法與常見陷阱：
  • return 做兩件事：交出值、結束函式。它後面同一層的程式碼都是死碼。
  • 函式沒有 print 也能把結果交給呼叫端，畫面上有沒有字是 print 負責的事。

Q-11-02-R02一次回傳兩個值 運行追蹤

對應 單元 11.2

下列 Python 程式執行後，畫面上印出的結果為何？

def divide(a, b):
    return a // b, a % b

q, r = divide(17, 5)
t = divide(9, 4)
print(q, r, t)
🎉 答對了！標準答案是 (A)
⚡ 速解

17 // 5 是 3，17 % 5 是 2，被兩個名字拆開。t 只有一個名字，接到整個元組 (2, 1)，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • return a // b, a % b 是回傳一個元組 (商, 餘數)。
  • q, r = divide(17, 5)：元組是 (3, 2)，被拆給 q 與 r，所以 q 是 3、r 是 2。
  • t = divide(9, 4)：元組是 (2, 1)，整個放進 t。
  • 印出 3 2 (2, 1)。故選 (A)。
  1. 選項逐項診斷：
  • (A) 逗號把兩個值打包成元組。左邊兩個名字接力解包得 3、2；只用一個名字 t 接，就是整個元組 (2, 1)。
  • (B) 以為 t 會被拆開。只有左邊有兩個名字時才會解包，t 一個名字接到的是整個元組。
  • (C) 以為 q、r 都拿到整個元組。左邊有兩個名字，元組會被拆開，各拿一個。
  • (D) 回傳打包出來的是元組，不是串列，印出來是小括號。
  1. APCS 考場心法與常見陷阱：
  • 函式要交出多個值，用逗號隔開就好，實際上回傳的是一個元組。
  • 左邊名字的個數要和元組長度一致才能解包。只寫一個名字，就會拿到整個元組。

對應 單元 11.2

預期只印出一行 12。空格應填入哪一個？

def area(w, h):
    ______

print(area(3, 4))
🎉 答對了！標準答案是 (C)
⚡ 速解

外面已經有 print，函式只要把結果「交出來」，不要自己再印。只有 return w * h 秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 外層的 print(area(3, 4)) 會把函式的回傳值印出來。
  • 所以函式只能「回傳」12，不能自己再 print，否則畫面上會多一行 None。
  • 只算不回傳（w * h）會讓回傳值變成 None。
  • return w * h 剛好交出 12。故選 (C)。
  1. 選項逐項診斷：
  • (A) 函式裡先印出 12，沒有回傳，外面的 print(area(3, 4)) 再印出 None，畫面上有兩行。
  • (B) 只算了一次、沒有人接住，函式沒有回傳值，印出 None。
  • (C) 把 12 交給呼叫端，外面的 print 印出 12，只有一行。
  • (D) 回傳的是兩個值打包成的元組，印出 (3, 4)。
  1. APCS 考場心法與常見陷阱：
  • 外面有 print(函式()) 時，函式裡不要再 print 同一個結果，否則多一行，還會多一個 None。
  • 忘了寫 return 是常見錯誤，結果永遠是 None。

Q-11-02-F02衛語句要提早交出值 程式填空

對應 單元 11.2

預期印出 -1 3。空格應填入哪一個？

def safe_div(a, b):
    if b == 0:
        ______
    return a // b

print(safe_div(8, 0), safe_div(9, 3))
🎉 答對了！標準答案是 (D)
⚡ 速解

衛語句要「結束函式」而且「交出 -1」。pass 與 print 都不會結束，return 單獨用交出 None，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • safe_div(8, 0)：b 是 0，進入 if。
  • 要擋住除以 0，必須在這裡結束函式並交出 -1，所以填 return -1。
  • safe_div(9, 3)：b 不是 0，往下做 9 // 3 = 3。
  • 印出 -1 3。故選 (D)。
  1. 選項逐項診斷：
  • (A) 什麼都不做，往下掉到 a // b，除以 0 丟出 ZeroDivisionError。
  • (B) 印完 -1 之後函式沒有結束，仍往下做 8 // 0，丟出 ZeroDivisionError。
  • (C) 有結束函式，但沒有帶值，回傳 None，印出 None 3。
  • (D) b 是 0 時直接交出 -1 並結束，不會執行除法。safe_div(9, 3) 是 3。印出 -1 3。
  1. APCS 考場心法與常見陷阱：
  • 衛語句的寫法：先處理不合法的情況，直接 return，讓正常流程留在下面。
  • 只印出警告不夠。只有 return 才會真的讓函式提早結束。

想印出 25。現在畫面印出 9 和 16 之後，丟出 TypeError: unsupported operand type(s) for +: 'NoneType' and 'NoneType'。只改函式裡的一行，哪一個改法會印出預期結果？

def square(n):
    print(n * n)

total = square(3) + square(4)
print(total)
🎉 答對了！標準答案是 (A)
⚡ 速解

加法需要真正的數字，不是畫面上的字。函式要用 return n * n 把數字交出來，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 現況：square 只印出平方，沒有 return，兩次呼叫的結果都是 None。
  • None + None 沒辦法相加，所以 TypeError。
  • 改成 return n * n，兩次呼叫分別得到 9 與 16。
  • 9 + 16 是 25，最後 print(total) 印出 25。故選 (A)。

  • (D) print 本身回傳 None，回傳的還是 None，而且會先把 9 和 16 印出來。
  1. APCS 考場心法與常見陷阱：
  • print 是給人看的，return 才是給程式用的。要拿結果去計算，就一定要 return。
  • 遇到 NoneType 的 TypeError，先檢查函式有沒有忘記 return。

Q-11-02-D02return 縮排進迴圈裡 測試除錯

對應 單元 11.2

想印出 6。現在印出 1。只改一處，哪一個改法會印出預期結果？

def total(nums):
    s = 0
    for v in nums:
        s += v
        return s

print(total([1, 2, 3]))
🎉 答對了！標準答案是 (D)
⚡ 速解

return 縮排在迴圈裡面，第一圈就結束了，所以得到 1。把它移到迴圈外面，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 現況：第一圈 v 是 1，s 變成 1，return s 立刻交出 1，函式結束。
  • 要累加完才交出，return 必須放在迴圈外面，也就是與 for 同一層縮排。
  • 修正後迴圈跑 3 圈：1、3、6，最後回傳 6。
  • 故選 (D)。
  1. 選項逐項診斷：
  • (A) 每圈都重設，而且第一圈就 return，仍然是 1。
  • (B) 第一圈就結束，v 也是 1，仍然印出 1。
  • (C) 第一圈就結束，s 是 1，仍然印出 1。
  • (D) return 移到迴圈外面，迴圈跑完三圈累加得 6，再把 6 交出來。
  1. APCS 考場心法與常見陷阱：
  • 迴圈裡面的 return 會在第一次執行到就結束整個函式，不只是結束這一圈。
  • 累加後回傳的典型結構：迴圈外先設初值、迴圈內累加、迴圈外 return。

Q-11-02-P01提早 return 跳過的 print 效能分析

對應 單元 11.2

下列程式執行時，print(n, end=" ") 這一行共執行幾次？

def show(n):
    if n % 2 == 0:
        return
    print(n, end=" ")

for i in range(1, 8):
    show(i)
🎉 答對了！標準答案是 (C)
⚡ 速解

偶數會在 return 提早離開，只有奇數走到 print。1 到 7 的奇數有 4 個，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 迴圈 i 依序是 1 到 7，每個都呼叫一次 show(i)。
  • n 是偶數（2、4、6）時，if 成立，return 讓函式結束，沒執行 print。
  • n 是奇數（1、3、5、7）時，走到 print。
  • 共 4 次。故選 (C)。
  1. 選項逐項診斷：
  • (A) 這是 show 被呼叫的次數。偶數那幾次在 return 就結束了，沒走到 print。
  • (B) 這是偶數的個數（2、4、6）。走到 print 的是奇數。
  • (C) i 從 1 到 7。奇數 1、3、5、7 不會被 return 擋下，各執行一次 print，共 4 次。
  • (D) 多加了一個。range(1, 8) 只到 7，不會有 8。
  1. APCS 考場心法與常見陷阱：
  • 有提早 return 的函式，後面的程式不一定每次都會被執行。數次數要看有幾次走到那一行。
  • range(1, 8) 的右邊不包含 8。

Q-11-02-P02找到就提早結束 效能分析

對應 單元 11.2

下列程式執行時，print("?", end="") 這一行共執行幾次？

def find(nums, target):
    for v in nums:
        print("?", end="")
        if v == target:
            return True
    return False

find([4, 7, 2, 9], 7)
find([4, 7, 2, 9], 5)
🎉 答對了！標準答案是 (A)
⚡ 速解

找 7：看了 4、7 就停，2 次。找 5：整串走完，4 次。2 + 4 = 6，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • find([4, 7, 2, 9], 7)：v 是 4，印 ?，不等於 7。v 是 7，印 ?，等於 7，return True，函式結束。共 2 次。
  • find([4, 7, 2, 9], 5)：4、7、2、9 都不等於 5，每個都印一次，迴圈跑完 return False。共 4 次。
  • 2 + 4 = 6。故選 (A)。
  1. 選項逐項診斷：
  • (A) 第一次找 7：先處理 4 再處理 7，找到就 return，只執行 2 次。第二次找 5：找不到，4 個都走過，執行 4 次。2 + 4 = 6。
  • (B) 以為兩次呼叫都把四個數走完。第一次在第二個數就找到了。
  • (C) 只算了第一次找到 7 的次數，漏掉第二次找不到的整趟。
  • (D) 只算了第二次整趟的 4 次，漏掉第一次提早結束的 2 次。
  1. APCS 考場心法與常見陷阱：
  • 找到就 return 的搜尋，最好情況很快，最差情況要整串走完。數次數時兩種都要分別算。
  • print 寫在 if 的前面，所以先印再判斷，找到的那一次也要算進去。

Q-11-02-L01這個判定函式在判定什麼 計算邏輯

對應 單元 11.2

下列程式印出 False True False True。哪一句描述 f(n) 判斷什麼，換成其他整數 n 也成立？

def f(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

print(f(1), f(2), f(9), f(11))
🎉 答對了！標準答案是 (B)
⚡ 速解

小於 2 就 False，從 2 試到 n - 1 只要有一個整除就 False，都除不盡才 True，這是質數判斷，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 衛語句：n < 2 直接回傳 False，所以 f(1) 是 False。
  • f(2)：range(2, 2) 是空的，迴圈不跑，回傳 True。
  • f(9)：d 走到 3 時 9 % 3 == 0，回傳 False。f(11)：2 到 10 都除不盡，回傳 True。
  • 推到其他數：f(13) 是 True，f(15)（15 % 3 為 0）是 False，f(7) 是 True，f(4) 與 f(8) 是 False。符合的描述是質數判斷。故選 (B)。
  1. 選項逐項診斷：
  • (A) f(1)、f(2)、f(9)、f(11) 剛好都對得上，但 f(7) 實際是 True，7 除以 3 餘 1 的推論不成立。
  • (B) 小於 2 的直接 False；2 到 n - 1 都除不盡才是 True，這就是質數的定義。13 是質數，15 能被 3 整除。
  • (C) 四個輸出都對得上，但 f(4) 實際是 False（4 能被 2 整除），推論不成立。
  • (D) 四個輸出都對得上，但 f(8) 實際是 False（8 能被 2 整除），推論不成立。
  1. APCS 考場心法與常見陷阱：
  • 判定函式要看程式的邏輯，不是只配幾組輸出。其他選項都是刻意讓前四組輸出剛好吻合。
  • 判定函式的回傳值是布林值，呼叫端可以直接放進 if 條件使用。

Q-11-02-L02回傳的兩個值各是什麼 計算邏輯

對應 單元 11.2

下列程式印出 5 9。哪一句描述 span 回傳的兩個值，換成其他引數也成立？

def span(a, b, c):
    return max(a, b, c) - min(a, b, c), max(a, b, c)

x, y = span(4, 9, 6)
print(x, y)
🎉 答對了！標準答案是 (C)
⚡ 速解

函式回傳的是「最大減最小」與「最大」。換成 8、3、5 就是 (5, 8)，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • return 後面兩個式子用逗號分開，回傳 (max(a, b, c) - min(a, b, c), max(a, b, c))。
  • span(4, 9, 6)：最大 9、最小 4，回傳 (5, 9)，x 是 5，y 是 9。
  • 換成 span(8, 3, 5)：最大 8、最小 3，回傳 (5, 8)。
  • 只有一個選項對所有引數都成立。故選 (C)。
  1. 選項逐項診斷：
  • (A) span(4, 9, 6) 的 9 − 4 剛好是 5，但 span(8, 3, 5) 實際是 (5, 8)，x 不是 0。
  • (B) span(4, 9, 6) 的 9 − 4、9 剛好對上，但 span(8, 3, 5) 實際是 (5, 8)，函式從頭到尾沒有按引數位置取值。
  • (C) 函式回傳 (max - min, max)。span(8, 3, 5) 是 (8 − 3, 8)，也就是 5 8。
  • (D) span(4, 9, 6) 的第二個引數剛好是最大值 9，但 span(8, 3, 5) 的 y 實際是最大值 8，不是 3。
  1. APCS 考場心法與常見陷阱：
  • 題目給的範例剛好把三個數的最大值放在第二個引數，容易讓人誤以為 y 是 b。換一組數就能驗證。
  • 多值回傳的第一個式子對應 x，第二個式子對應 y，位置不會對調。

Q-11-03-R01整數傳進去，外面的值不變 運行追蹤

對應 單元 11.3

下列 Python 程式執行後，畫面上印出的結果為何？

def bump(n):
    n += 10
    return n

x = 5
y = bump(x)
print(x, y)
🎉 答對了！標準答案是 (D)
⚡ 速解

整數改了只是函式裡的 n 換了新值，外面的 x 不會變。x 是 5，y 接到回傳的 15，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • bump(x)：n 一開始也是 5。
  • n += 10 之後 n 變成 15。這只是函式裡的名字 n 換了指向，外面的 x 沒有被碰到。
  • return n 把 15 交出來，存進 y。
  • 印出 5 15。故選 (D)。
  1. 選項逐項診斷：
  • (A) 以為函式裡改了 n，外面的 x 也跟著變。整數是不可變的，n += 10 是讓 n 指向新的整數 15。
  • (B) 漏看 return n。函式把 15 交了出來，y 接到的是 15，不是 5。
  • (C) 把 x 和 y 的值弄反了。x 還是 5，y 才是函式回傳的 15。
  • (D) n 一開始與 x 同一個 5，n += 10 之後 n 指向 15，x 沒動。回傳 15 存進 y。
  1. APCS 考場心法與常見陷阱：
  • 整數、字串、元組都不可變。函式裡對參數做運算，外面的原變數不會被改。
  • 想把算出的結果帶出來，要靠 return，再由呼叫端接住。

Q-11-03-R02串列傳進去，原處被改 運行追蹤

對應 單元 11.3

下列 Python 程式執行後，畫面上印出的結果為何？

def add_end(box, v):
    box.append(v)

a = [1, 2]
b = a
add_end(a, 9)
print(a, b, len(a))
🎉 答對了！標準答案是 (B)
⚡ 速解

b = a 與傳進函式的 box 都是同一份串列，append 原處改，所以 a、b 都變，長度是 3，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • a = [1, 2]。b = a：b 指向同一個串列，不是新的一份。
  • add_end(a, 9)：box 也指向這一個串列，box.append(9) 直接把 9 加在它後面。
  • 這時同一個串列變成 [1, 2, 9]，a 和 b 看到的都是它。
  • len(a) 是 3。印出 [1, 2, 9] [1, 2, 9] 3。故選 (B)。
  1. 選項逐項診斷：
  • (A) 以為 b = a 做了一份新的。這一行只是多一個名字指向同一個串列，b 也會看到 9。
  • (B) a、b、函式裡的 box 都指向同一個串列。append(9) 就地改，三個名字看到的都是 [1, 2, 9]，長度 3。
  • (C) 以為函式裡的修改不會影響外面。串列是可變的，append 直接改原串列。
  • (D) len(a) 是在改完之後才算的。串列現在有 3 個元素。
  1. APCS 考場心法與常見陷阱：
  • 串列、字典可變。函式用 append、sort 等方法改它，外面的原串列會跟著變。
  • b = a 不會複製串列，只是多了一個名字。要複製要用 .copy() 或切片。

對應 單元 11.3

預期印出 [1, 2, 3] [3, 1, 2]，也就是排序後的結果出現，外面的 data 保持原樣。空格應填入哪一個？

def sorted_view(nums):

data = [3, 1, 2]

Q-11-03-P01append 被執行的次數 效能分析

對應 單元 11.3

下列程式執行時，box.append(len(box)) 這一行共執行幾次？

def grow(box):
    box.append(len(box))

data = []
for i in range(4):
    grow(data)
for v in data:
    grow([v])
🎉 答對了！標準答案是 (B)
⚡ 速解

第一個迴圈 4 次，讓 data 有 4 個元素；第二個迴圈走訪這 4 個元素，再 4 次。共 8 次，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 第一個迴圈 range(4)：grow(data) 呼叫 4 次，append 執行 4 次。data 變成 [0, 1, 2, 3]。
  • 第二個迴圈走訪 data 的 4 個元素，每個元素呼叫一次 grow([v])，append 又執行 4 次。
  • grow([v]) 傳的是新串列，不會讓 data 變長，所以迴圈不會變多。
  • 4 + 4 = 8。故選 (B)。
  1. 選項逐項診斷：
  • (A) 只算了第一個迴圈。第二個迴圈也會呼叫 grow。
  • (B) 第一個迴圈呼叫 4 次，data 變成 4 個元素。第二個迴圈對這 4 個元素各呼叫一次，又 4 次。4 + 4 = 8。
  • (C) 以為第二個迴圈對每個元素都再重複 4 次。每個元素只呼叫一次 grow。
  • (D) 少數了一次。兩個迴圈各是 4 次，合計是 8。
  1. APCS 考場心法與常見陷阱：
  • 第二個迴圈傳的是 [v] 這份新串列，改它不會影響 data，所以走訪的次數固定是 4。
  • 數執行次數時，先算各段迴圈的次數，再相加。

下列程式執行時，s += v 這一行共執行幾次？

    return s

total(data)
total(data)
total(data[:2])

⚡ 速解

total(data) 兩次各 3 圈，data[:2] 只有 2 個元素，2 圈。6 + 2 = 8，秒選 (C)。

  • total(data)：data 有 3 個元素，tmp 是複本也是 3 個，迴圈 3 圈。
  • 再呼叫一次，又是 3 圈。累計 6 圈。

  • (A) 只算了一次呼叫的次數。total 被呼叫了三次。

  • (D) 漏掉第三次呼叫的 2 次。

  • .copy() 不會改變元素的個數，所以迴圈次數和原串列一樣。

Q-11-03-L01這個函式回傳什麼、動了誰 計算邏輯

對應 單元 11.3

下列程式印出 [9, 7] [4, 9, 2, 7]。哪一句描述 g(nums, k)，換成其他串列也成立？

def g(nums, k):
    out = []
    for v in nums:
        if v > k:
            out.append(v)
    return out

a = [4, 9, 2, 7]
print(g(a, 5), a)
🎉 答對了！標準答案是 (B)
⚡ 速解

函式依序檢查每個 v > k，符合的放進新的 out，不碰 nums。換成 8、3、6、9 與 5，得 [8, 6, 9]，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • out 一開始是空串列，迴圈依序檢查 nums 的每個元素。
  • v > k 成立的才 append 進 out。nums 自己沒被修改，所以外面的 a 不變。
  • g(a, 5)：9 與 7 大於 5，得 [9, 7]。
  • 換成 [8, 3, 6, 9] 與 5：8、6、9 都大於 5，得 [8, 6, 9]。故選 (B)。
  1. 選項逐項診斷：
  • (A) 題目範例的奇數下標剛好是 9 與 7，但函式裡是用 v > k 判斷，跟下標無關。實際得 [8, 6, 9]。
  • (B) 函式用 v > k 篩選，放進新的 out，並沒有改 nums。g([8, 3, 6, 9], 5) 的結果是 [8, 6, 9]。
  • (C) 範例中大於第一個元素 4 的剛好也是 9 與 7，但函式比的是 k，不是第一個元素。實際得 [8, 6, 9]。
  • (D) 範例只有兩個符合，看起來像「只取兩個」。函式沒有數量限制，實際三個都放進去。
  1. APCS 考場心法與常見陷阱：
  • 判斷一個函式有沒有副作用，看它是 append 進自己建立的新串列，還是直接改傳進來的串列。
  • 其他選項都是從範例輸出倒推出來的巧合，換一組資料就露餡。

Q-11-03-L02重新指向和就地修改 計算邏輯

對應 單元 11.3

下列程式印出 [1] [1, 0]。哪一句描述 f(a, b) 的效果，換成其他呼叫也成立？

def f(a, b):
    a = a + [0]
    b.append(0)

x = [1]
y = [1]
f(x, y)
print(x, y)
🎉 答對了！標準答案是 (C)
⚡ 速解

a = a + [0] 是換了新串列，外面不動；b.append(0) 是原處加。f(s, s) 時 b 就是 s，所以 s 變 [1, 0]，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • a = a + [0]：做出新串列再讓 a 指向它。原本的串列沒變，所以 x 不變。
  • b.append(0)：直接在 b 指向的串列上加元素，所以 y 多了一個 0。
  • f(s, s)：a 與 b 都指向 s。a 改指新串列後，s 沒被動；b.append(0) 讓 s 多一個 0，成為 [1, 0]。
  • 故選 (C)。
  1. 選項逐項診斷：
  • (A) 不是看位置。f(s, s) 時 b 就是 s，b.append(0) 會把 0 加進 s，s 變成 [1, 0]。
  • (B) a + [0] 會產生新串列，只是讓 a 改指向它，不會改到 s。s 只被 append 加了一個 0。
  • (C) a = a + [0] 是重新指向，不影響外面。b.append(0) 是就地改，b 就是 s，所以 s 多了一個 0，成為 [1, 0]。
  • (D) a + [0] 的 0 加在後面，也不會改動原串列。這個推論連題目範例的 x 都不符。
  1. APCS 考場心法與常見陷阱：
  • 賦值（=）是讓名字改指別處，不會動到原本的物件；append、sort 是在原物件上動手。
  • 同一個串列被兩個參數同時接到時，從任何一個名字改，另一個名字看到的都一樣。

  • 外面 x = 10。呼叫 f() 時，函式裡的 x = 3 是在函式內部新建立的區域變數，與外面的 x 同名但是兩個不同的東西。

預期印出 1 1 0，每次呼叫都從 0 開始算，外面的 count 不變。空格應填入哪一個？

count = 0

def tick():
    ______
    count += 1
    return count

print(tick(), tick(), count)
🎉 答對了！標準答案是 (B)
⚡ 速解

函式裡有 count += 1，count 就是區域變數，必須先在函式裡設初值 0。只有 count = 0 能得到 1，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 函式裡有 count += 1，等於 count = count + 1，所以 count 是這個函式的區域變數。
  • 區域變數在使用之前要先有值，否則是 UnboundLocalError。外面的 count = 0 不會被借來用。
  • 第一行填 count = 0：區域的 count 從 0 開始，加 1 得 1，回傳 1。
  • 兩次呼叫都是 1，外面的 count 仍是 0。印出 1 1 0。故選 (B)。
  1. 選項逐項診斷：
  • (A) count += 1 需要先有值，函式裡 count 是區域變數但還沒有值，丟出 UnboundLocalError。
  • (B) 函式裡自己先建立區域的 count 並設為 0，再加 1，回傳 1。每次呼叫都重新開始，外面的 count 仍是 0。
  • (C) 區域的 count 從 5 開始，加 1 得 6，印出 6 6 0。
  • (D) 只是讀取，但 count 在這個函式裡有指定，被視為區域變數，還沒有值，丟出 UnboundLocalError。
  1. APCS 考場心法與常見陷阱：
  • 函式裡只要有對某名字指定（=、+=），那個名字在整個函式裡都是區域變數。
  • 區域變數在函式結束時消失，下次呼叫會重新建立，不會記得上一次的值。

Q-11-04-P01每次呼叫都重新開始的計數 效能分析

對應 單元 11.4

下列程式執行時，c += 1 這一行共執行幾次？

def step(n):
    c = 0
    while n > 1:
        n //= 2
        c += 1
    return c

step(8)
step(5)
step(1)
🎉 答對了！標準答案是 (A)
⚡ 速解

每次呼叫 c 都重新從 0 開始，次數就是 n 減半到 1 的步數。8 是 3 次，5 是 2 次，1 是 0 次，共 5 次，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • step(8)：n 依序 8、4、2，每次減半，c += 1 執行 3 次，n 變 1 時停。
  • step(5)：n 是 5、2（5 // 2 是 2），執行 2 次，變 1 時停。
  • step(1)：1 > 1 不成立，迴圈不進去，0 次。
  • 3 + 2 + 0 = 5。故選 (A)。
  1. 選項逐項診斷：
  • (A) step(8)：8、4、2 各減半一次，共 3 次；step(5)：5、2 共 2 次；step(1) 一次都不進迴圈。3 + 2 + 0 = 5。
  • (B) 只算了 step(8)。三次呼叫都要算。
  • (C) 以為 step(1) 會進一次迴圈。1 > 1 不成立，迴圈一次也不跑。
  • (D) 把第一個引數 8 當成次數。迴圈每次都把 n 減半，不是減 1。
  1. APCS 考場心法與常見陷阱：
  • 每次呼叫的 c 與 n 都是全新的區域變數，彼此不影響，所以次數要分別算再相加。
  • // 是整數除法，5 // 2 是 2。

Q-11-04-P02內層迴圈隨外層增長 效能分析

對應 單元 11.4

下列程式執行時，s += 1 這一行共執行幾次？

def tri(n):
    s = 0
    for i in range(1, n + 1):
        for j in range(i):
            s += 1
    return s

tri(3)
tri(4)
🎉 答對了！標準答案是 (D)
⚡ 速解

tri(n) 的內層一共跑 1 + 2 + ... + n 次。3 是 6，4 是 10，共 16，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • tri(3)：i 依序 1、2、3，內層 range(i) 分別跑 1、2、3 次，共 6 次。
  • tri(4)：i 依序 1、2、3、4，內層分別跑 1、2、3、4 次，共 10 次。
  • 每次呼叫的 s 都從 0 重新開始，不影響次數的計算。
  • 6 + 10 = 16。故選 (D)。
  1. 選項逐項診斷：
  • (A) 把兩次呼叫的引數 3 和 4 直接相加。迴圈裡還有內層迴圈，次數不是引數本身。
  • (B) 把兩次呼叫的引數 3 和 4 直接相乘。內層次數隨 i 變，不是固定的乘法。
  • (C) 只算了 tri(4)，漏掉 tri(3) 的 6 次。
  • (D) tri(3)：i 是 1、2、3，內層各跑 1、2、3 次，共 6 次。tri(4) 內層各跑 1、2、3、4 次，共 10 次。6 + 10 = 16。
  1. APCS 考場心法與常見陷阱：
  • 內層迴圈次數隨外層變數改變時，要逐圈寫出來相加，不能直接乘。
  • 1 + 2 + ... + n 等於 n * (n + 1) // 2，可以拿來檢查。

下列程式印出 3 3。哪一句描述 f(nums) 的行為，換成其他串列也成立？

k = 3

def f(nums):
    k = 0
    for v in nums:
        if v % 2 == 0:
            k += 1
    return k

print(f([2, 5, 8, 4]), k)
🎉 答對了！標準答案是 (C)
⚡ 速解

函式裡的 k = 0 是區域變數，每遇到偶數加 1，是在數偶數的個數。[1, 3, 6, 7] 只有 6，得 1。外面的 k 不變，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 函式裡 k = 0 建立區域變數，與外面的 k = 3 無關。
  • 迴圈逐一檢查 v % 2 == 0，成立就把區域的 k 加 1，所以是偶數的個數。
  • 範例 [2, 5, 8, 4] 有 2、8、4 三個偶數，得 3。外面的 k 沒被改，仍是 3。

  1. 選項逐項診斷：
  • (A) 範例的長度是 4，減 1 剛好是 3。但函式是在數偶數，f([1, 3, 6, 7]) 實際得 1。
  • (B) 範例裡外面的 k 剛好也是 3，但函式回傳的是自己的區域 k，f([1, 3, 6, 7]) 實際得 1。
  • (C) 區域的 k 從 0 開始，每遇到偶數加 1。[1, 3, 6, 7] 只有 6 是偶數，得 1。外面的 k 沒被動到，仍是 3。
  • (D) 範例中大於 3 的元素有 5、8、4 三個，剛好也是 3。但函式裡 k 已經被設成 0，而且是在判斷偶數，實際得 1。
  1. APCS 考場心法與常見陷阱：
  • 範例輸出的兩個 3 純屬巧合：一個是偶數個數，一個是外面沒被改的 k。
  • 判斷函式在算什麼，要看函式本體，並用另一組資料驗證。

Q-11-04-L02區域變數用完就消失 計算邏輯

對應 單元 11.4

下列程式印出 6 3 6。哪一句描述 f(n)，換成其他整數 n 也成立？

def f(n):
    t = 0
    for i in range(n):
        t += i
    return t

print(f(4), f(3), f(4))
🎉 答對了！標準答案是 (B)
⚡ 速解

每次呼叫都建立新的 t = 0，用完就消失。0 到 n - 1 的總和，f(5) 是 10，再呼叫仍是 10，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • t 是函式裡的區域變數，每次呼叫從 t = 0 開始，函式結束時消失。
  • f(4)：0 + 1 + 2 + 3 得 6。f(3)：0 + 1 + 2 得 3。第二次 f(4) 又是 6，沒有受上一次影響。
  • 換成 n = 5：0 + 1 + 2 + 3 + 4 得 10，之後再呼叫仍是 10。
  • 故選 (B)。
  1. 選項逐項診斷：
  • (A) f(4) 是 6、f(3) 是 3 剛好都對得上，但迴圈是在加 0 到 n - 1，f(5) 實際得 10。
  • (B) 每次呼叫都建立新的區域 t = 0，結束就消失。f(4) 是 0+1+2+3 得 6，f(3) 是 0+1+2 得 3，f(5) 是 10。
  • (C) 與題目第三個輸出不符。f(4) 第二次仍是 6，不是接續累加的結果。
  • (D) 區域變數在函式結束時就消失了，外面沒有 t，丟出 NameError: name 't' is not defined。
  1. APCS 考場心法與常見陷阱：
  • 區域變數的生命週期是「呼叫開始到結束」，不會在兩次呼叫之間留下任何東西。
  • 函式外面想拿到結果，只能靠 return，不能靠偷看函式裡的變數。

Q-11-05-R01global 宣告與更新全域最佳解 運行追蹤

對應 單元 11.5

下列 Python 程式執行後，畫面上印出的結果為何？

ans = 100

def update(val):
    global ans
    if val < ans:
        ans = val

update(45)
update(70)
print(ans)
🎉 答對了！標準答案是 (A)
⚡ 速解

函式有 global ans，會維護全域最小值。45 比 100 小所以更新為 45；70 沒比 45 小故不更新，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 全域變數 ans = 100。
  • 第一次呼叫 update(45)：宣告 global ans，45 < 100 成立，全域 ans 被更新為 45。
  • 第二次呼叫 update(70)：70 < 45 不成立，不執行更新，全域 ans 維持 45。
  • 最後印出 ans 為 45。故選 (A)。
  1. 選項逐項診斷：
  • (A) ans 初值為 100。update(45) 透過 global ans 將全域變數改為 45；update(70) 條件 70 < 45 不成立，維持 45。
  • (B) 誤以為每次呼叫都會覆蓋全域變數，忽略了 if val < ans 只有在數值更小時才會更新。
  • (C) 誤以為函式內部無法修改全域變數。有宣告 global ans，可以修改全域變數。
  • (D) 有明確宣告 global ans，不會引發未綁定變數錯誤。
  1. APCS 考場心法與常見陷阱：
  • 在函式內部修改不可變型態（整數、浮點數、字串）的全域變數時，必須宣告 global。
  • APCS 競賽中常用 global 變數在 DFS/BFS 過程中即時維護全域最佳解（最小值或最大值）。

record(20)

    global ops
    for x in nums:
        if x > 0:
            ops += 1
        elif x == 0:
            ops += 2

process([0, -5, 2])
🎉 答對了！標準答案是 (D)
⚡ 速解

第一組：3(+1)、0(+2)、4(+1) 得 4；第二組：0(+2)、2(+1) 得 3。負數不執行，全域累計 4 + 3 = 7，秒選 (D)。

  1. 慢動作：
  • ops 為全域計數器，初值為 0。
  • 呼叫 process([3, -1, 0, 4])：
  • - x = 3 (>0)：ops += 1 (ops = 1)
  • - x = -1：不成立，略過
  • - x = 0 (==0)：ops += 2 (ops = 3)
  • - x = 4 (>0)：ops += 1 (ops = 4)
  • 呼叫 process([0, -5, 2])：
  • - x = 0 (==0)：ops += 2 (ops = 6)
  • - x = -5：不成立，略過
  • - x = 2 (>0)：ops += 1 (ops = 7)
  • 最終 ops 為 7。故選 (D)。
  1. 選項逐項診斷：
  • (A) 只計算了第一次呼叫 process([3, -1, 0, 4]) 的結果（1 + 2 + 1 = 4）。
  • (B) 只計算了第二次呼叫 process([0, -5, 2]) 的結果（2 + 1 = 3）。
  • (C) 誤將 0 的操作當作 1 次累加（1 + 1 + 1 + 1 + 1 = 5）。題目中 x == 0 時是 ops += 2。
  • (D) 第一次呼叫：3 (正數+1)、0 (零+2)、4 (正數+1)，累加 4；第二次呼叫：0 (零+2)、2 (正數+1)，累加 3。全域累積為 7。
  1. APCS 考場心法與常見陷阱：
  • 全域計數器在不同函式呼叫間會持續累加，不會自動重設。
  • 逐項追蹤條件分支，特別注意 x == 0 是加 2 而非加 1。

  • visited 是一個全域集合，一開始為空集合。

    if b == 0:
        return a
    return gcd(b, a % b)

🎉 答對了！標準答案是 (C)
⚡ 速解

  1. 慢動作：
  • 歐幾里得輾轉相除法原理：兩數的最大公因數等於其中較小數與兩數相除餘數的最大公因數。
  • 以 gcd(48, 18) 為例：
  • - 48 % 18 = 12 → 呼叫 gcd(18, 12)
  • - 18 % 12 = 6 → 呼叫 gcd(12, 6)

  • - b == 0 終止，回傳 a 即 6。

  • (A) 範例中 48 與 18 最大是 48，但印出 6，顯然不是求最大值。
  • (B) 48 // 18 是 2 不是 6，與題目輸出完全不合。
  • (C) 這是歐幾里得輾轉相除法演算法，以餘數遞迴求解最大公因數，35 與 14 的 GCD 為 7。
  • (D) 48 - 18 是 30，不是 6，推論不成立。
  1. APCS 考場心法與常見陷阱：
  • gcd(b, a % b) 是所有程式競賽（含 APCS）出場率最高的終極經典遞迴函式，必須一眼看懂！
  • 當 a < b 時（例如 gcd(14, 35)），第一步 14 % 35 = 14 會自動把兩數位置對調成 gcd(35, 14)。

  • 若只寫一個等號判斷，偶數或奇數路徑很容易直接「穿透」終止線掉入深淵。

Q-11-07-L01巴斯卡三角形組合數的雙分支遞迴 計算邏輯

下列程式印出 6。哪一句描述 c(n, k) 的計算意義，換成其他非負整數（$n \ge k \ge 0$）也成立？

    if k == 0 or k == n:
        return 1
    return c(n - 1, k - 1) + c(n - 1, k)

print(c(4, 2))
🎉 答對了！標準答案是 (B)
⚡ 速解

巴斯卡恆等式 $C(n, k) = C(n-1, k-1) + C(n-1, k)$，邊界皆為 1，這是組合數計算。$C(5, 2) = 10$，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 巴斯卡三角原理（組合數性質）：從 $n$ 人中選 $k$ 人，若包含某特定人，則從剩下 $n-1$ 人選 $k-1$ 人；若不含該人，則從剩下 $n-1$ 人選 $k$ 人。
  • 即 $C(n, k) = C(n-1, k-1) + C(n-1, k)$。
  • 邊界條件：選 0 人只有 1 種方法；全選只有 1 種方法，故 k == 0 or k == n 時回傳 1。
  • 換成 c(5, 2)：$C(5, 2) = \frac{5 \times 4}{2 \times 1} = 10$。故選 (B)。
  1. 選項逐項診斷：
  • (A) 排列數考慮順序，$P(4, 2) = 12$ 與印出的 6 不合。
  • (B) 巴斯卡定理公式 $C(n, k) = C(n-1, k-1) + C(n-1, k)$，$C(4, 2)=6$，$C(5, 2)=10$。
  • (C) 範例中 4 與 2 的公因數是 2 不是 6，完全不符。
  • (D) $4^2 = 16$ 與 6 不符。
  1. APCS 考場心法與常見陷阱：
  • 組合數雙分支遞迴是離散數學與演算法最常見的範例之一。
  • 注意識別邊界條件：k == 0 或 k == n 時為 1。

  • - pattern(1) = 'A'（長度 1）

  • (A) 111 並非質數（$111 = 3 \times 37$），is_prime(111) 會回傳 False。
  • (B) 漏掉了 11。11 本身為迴文且為質數。
  • (C) 121 並非質數（$121 = 11 \times 11$），is_prime(121) 為 False。
  • (D) 在 10 到 150 之間，同時滿足迴文數與質數的整數剛好為 11, 101, 131。
  1. APCS 考場心法與常見陷阱：
  • 將「是否為質數」與「是否為迴文」各自封裝為獨立輔助函式，主迴圈只需用 if is_prime(x) and is_pal(x)，語意極其清晰。
  • 這種 Top-Down 拆題方式能大幅降低 APCS 實作題的思維負擔與 Bug 產生率。

Q-11-08-F01網格索引邊界檢查的開閉區間 程式填空

對應 單元 11.8

預期印出 True False（$H=3, W=4$ 時，行索引 3 在範圍內，但列索引 3 已出界）。空格應填入哪一個？

def in_bound(r, c, H, W):
    return ______

print(in_bound(0, 3, 3, 4), in_bound(3, 2, 3, 4))
🎉 答對了！標準答案是 (B)
⚡ 速解

合法索引從 0 到 H-1，所以嚴格小於長度：0 <= r < H and 0 <= c < W，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 在 Python 串列中，長度為 $H$ 的容器其合法索引下標為 $0, 1, \dots, H-1$。
  • 若下標等於 $H$，存取時會造成越界錯誤（IndexError）。
  • 因此邊界條件必須同時滿足：
  • - 列索引：$0 \le r < H$
  • - 行索引：$0 \le c < W$
  • 連鎖比對語法寫作 0 <= r < H and 0 <= c < W。故選 (B)。
  1. 選項逐項診斷：
  • (A) 使用了 <=，當 $r=H$ 時等於最大長度，存取 grid[r] 會發生 IndexError。
  • (B) Python 下標從 0 起算，合法範圍為 0 到 $H-1$ 與 0 到 $W-1$（即左閉右開 0 <= r < H）。
  • (C) 使用 or 且未檢查負數，會讓非法坐標通過判定。
  • (D) 排除了 0，導致最上方列 $r=0$ 與最左側行 $c=0$ 被誤判為出界。
  1. APCS 考場心法與常見陷阱：
  • APCS 網格題的「長寬混淆」與「邊界 Off-by-one 差一」是失分大宗，牢記邊界為左閉右開 0 <= r < H。
  • Python 支援連續比較 0 <= r < H，比其他語言寫兩次 r >= 0 && r < H 更加簡潔防錯。

Q-11-08-F02幾何輔助函式曼哈頓距離計算 程式填空

對應 單元 11.8

預期計算兩點坐標 $(1, 5)$ 與 $(4, 1)$ 的曼哈頓距離，印出 7。空格應填入哪一個？

def manhattan(p1, p2):
    r1, c1 = p1
    r2, c2 = p2
    return ______

print(manhattan((1, 5), (4, 1)))
🎉 答對了！標準答案是 (C)
⚡ 速解

曼哈頓距離是橫坐標差與縱坐標差的絕對值相加：abs(r1 - r2) + abs(c1 - c2)，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 曼哈頓距離（Manhattan Distance）定義為兩點在方格網上的路徑總長：
  • $D = |r_1 - r_2| + |c_1 - c_2|$。
  • 代入點 $(1, 5)$ 與 $(4, 1)$：
  • $|1 - 4| + |5 - 1| = |-3| + |4| = 3 + 4 = 7$。
  • 因此空格處填入 abs(r1 - r2) + abs(c1 - c2)。故選 (C)。
  1. 選項逐項診斷：
  • (A) 未取絕對值，$(1 - 4) + (5 - 1) = -3 + 4 = 1$，計算錯誤。
  • (B) 誤將同一個點的列行相減，而不是兩點同坐標軸相減。
  • (C) 曼哈頓距離公式：兩點水平距離差絕對值加上垂直距離差絕對值，$|1 - 4| + |5 - 1| = 3 + 4 = 7$。
  • (D) 這是歐幾里得直線距離公式（開根號），算出來是浮點數 5.0。
  1. APCS 考場心法與常見陷阱：
  • 曼哈頓距離在 APCS 模擬與搜尋題目中頻繁出現（例如計程車行駛、機器人移動步數）。
  • 解包元組坐標 r1, c1 = p1 能讓公式可讀性大幅提升。

Q-11-08-D01質數判定輔助函式邊界 1 誤判 測試除錯

對應 單元 11.8

想正確篩選出串列中的質數印出 [2, 3]。現在執行卻印出 [1, 2, 3]（數字 1 被誤判為質數）。只改動函式開頭一處，哪一個改法會印出預期結果？

def is_prime(n):
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

print([x for x in [1, 2, 3, 4] if is_prime(x)])
🎉 答對了！標準答案是 (A)
⚡ 速解

1 不是質數。當 n=1 時 range(2, 1) 是空的直接回傳了 True。在開頭加上衛語句 if n < 2: return False 即可修正，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 現況：依數學定義，質數必須是大於 1 的自然數，1 既不是質數也不是合數。
  • 當 n = 1 傳入函式時，range(2, 1) 的起點大於終點，迴圈為空完全不執行。
  • 函式直接執行最後一行的 return True，導致 1 被誤判為質數。
  • 解法：在迴圈前加入防禦衛語句 if n < 2: return False，立即修正。故選 (A)。
  1. 選項逐項診斷：
  • (A) 加上衛語句防禦，將小於 2 的整數（含 1）直接判定為非質數，正確印出 [2, 3]。
  • (B) 任何數除以 1 餘數皆為 0，會使所有大於等於 2 的數都在第一步返回 False。
  • (C) 會使所有數字都被判定為非質數，回傳空串列 []。
  • (D) 因數判定邏輯顛倒，產生嚴重邏輯錯誤。
  1. APCS 考場心法與常見陷阱：
  • 寫數論演算法時，永遠要優先檢查邊界極值：0, 1 以及負數。
  • 單元測試（Unit Test）思維：在撰寫主程式前，先單獨呼叫 is_prime(1) 檢查其是否回傳 False。

Q-11-08-D02多參數輔助函式呼叫引數位置顛倒 測試除錯

對應 單元 11.8

想檢查分數 82 與及格線 60 的差距是否在限制 15 分以內（差距為 22，應為 False）。現在執行卻印出 True。只改動 is_near_pass 內部一行，哪一個改法會印出預期結果 False？

def dist(x, y):
    return abs(x - y)

def check_range(target, current, limit):
    return dist(current, target) <= limit

def is_near_pass(score):
    return check_range(60, 15, score)

print(is_near_pass(82))
🎉 答對了！標準答案是 (D)
⚡ 速解

原本呼叫把 current 傳成了 15、limit 傳成了 82。調整為 check_range(60, score, 15) 讓 limit 是 15，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 檢視 check_range(target, current, limit) 的參數定義：
  • - 第 1 個參數：基準目標 target
  • - 第 2 個參數：當前數值 current
  • - 第 3 個參數：最大容許誤差 limit
  • 原程式呼叫 check_range(60, 15, score)：
  • - 導致 current = 15，limit = score = 82！
  • - 計算 abs(15 - 60) = 45 <= 82，結果被誤算為 True。
  • 將其更正為 check_range(60, score, 15)，計算 abs(82 - 60) = 22 <= 15 為 False。故選 (D)。
  1. 選項逐項診斷：
  • (A) 將 limit 傳入 score (82)，條件依然成立回傳 True。
  • (B) 參數混淆，無法正確表達及格線為 60 與容許差距為 15 的語意。
  • (C) 容許差距被設為 60，22 <= 60 依然回傳 True。
  • (D) 正確依位置傳入 target=60, current=score, limit=15，計算 |82 - 60| = 22 <= 15 為 False。
  1. APCS 考場心法與常見陷阱：
  • 模組化呼叫時，位置引數（Positional Arguments）必須嚴格與定義時的語意順序逐一對齊。
  • 參數數量較多時，容易發生「型態相同但語意對調」的隱蔽 Bug，呼叫端需格外小心核對。

Q-11-08-P01前置過濾保護下游函式的執行次數 效能分析

對應 單元 11.8

在 process([4, -2, 7, 6, 0, 8]) 執行期間，輔助函式 transform 總共被呼叫了幾次？

def valid(x):
    return x > 0 and x % 2 == 0

def transform(x):
    return x * 2

def process(nums):
    res = []
    for v in nums:
        if valid(v):
            res.append(transform(v))
    return res

process([4, -2, 7, 6, 0, 8])
🎉 答對了！標準答案是 (A)
⚡ 速解

只有正偶數（4, 6, 8）能通過 valid 驗證，因此 transform 僅被呼叫 3 次，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 走訪串列中的 6 個數字：
  • - v = 4：4 > 0 且為偶數，valid(4) 為 True → 呼叫 transform(4)（第 1 次）
  • - v = -2：非正數，valid 為 False，不呼叫
  • - v = 7：奇數，valid 為 False，不呼叫
  • - v = 6：正偶數，valid 為 True → 呼叫 transform(6)（第 2 次）
  • - v = 0：非大於 0，valid 為 False，不呼叫
  • - v = 8：正偶數，valid 為 True → 呼叫 transform(8)（第 3 次）
  • 總計呼叫 transform 3 次。故選 (A)。
  1. 選項逐項診斷：
  • (A) 只有在 valid(v) 為 True（正偶數）時才會呼叫 transform。串列中只有 4, 6, 8 符合條件，共呼叫 3 次。
  • (B) 誤以為串列中的 6 個元素都會呼叫 transform。忽略了 if valid(v) 的前置過濾。
  • (C) 誤將 0 或 -2 也當作有效數字。
  • (D) 計算失誤，漏算了其中一個正偶數。
  1. APCS 考場心法與常見陷阱：
  • 透過驗證函式在前置把關，可以大幅避免下游計算函式處理非法或無效數據。
  • 數呼叫次數時，務必將「條件短路過濾」的影響納入考量。

Q-11-08-P02多層條件過濾下的子函式呼叫次數 效能分析

對應 單元 11.8

在迴圈執行時，函式 is_multiple_of_three 總共被呼叫了幾次？

def is_even(n):
    return n % 2 == 0

def is_multiple_of_three(n):
    return n % 3 == 0

nums = list(range(1, 13))
count = 0
for x in nums:
    if is_even(x):
        if is_multiple_of_three(x):
            count += 1
🎉 答對了！標準答案是 (D)
⚡ 速解

只有偶數才會進到內層呼叫 is_multiple_of_three。1 到 12 有 6 個偶數，故呼叫 6 次，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • nums 包含 1 到 12 共 12 個整數。
  • 第一層過濾 if is_even(x): 只有在偶數時成立：
  • - 偶數集合：[2, 4, 6, 8, 10, 12]，共 6 個數。
  • 對於這 6 個數字，程式才會進入內層並執行 if is_multiple_of_three(x):。
  • 因此 is_multiple_of_three 共被呼叫 6 次。故選 (D)。
  1. 選項逐項診斷：
  • (A) 誤以為外層迴圈走 12 次就會呼叫 12 次。該函式位於 if is_even(x) 內部。
  • (B) 這是最終同時滿足兩條件的計數結果（6 與 12 共 2 個），不是呼叫次數。
  • (C) 計算 1 到 12 中 3 的倍數個數（3, 6, 9, 12），但奇數的 3 和 9 進不到內層。
  • (D) 只有當 is_even(x) 為 True 時才會呼叫內層函式。1 到 12 的偶數有 2, 4, 6, 8, 10, 12 共 6 個。
  1. APCS 考場心法與常見陷阱：
  • 多重條件過濾時，將判斷條件由「計算開銷小」排到「計算開銷大」，能顯著減少繁重函式的呼叫頻率。
  • 注意審題：問的是「特定函式呼叫次數」，而非最後的累計結果 count。

Q-11-08-L01幾何象限與坐標同號異號判定邏輯 計算邏輯

對應 單元 11.8

下列程式印出 SAME SAME DIFF。哪一句描述 classify(x, y) 的判斷邏輯，換成其他非零整數坐標也成立？

def classify(x, y):
    if x == 0 or y == 0:
        return "AXIS"
    if x * y > 0:
        return "SAME"
    return "DIFF"

print(classify(3, 5), classify(-2, -4), classify(4, -1))
🎉 答對了！標準答案是 (B)
⚡ 速解

相乘大於 0 即兩數同正或同負（同號 SAME），否則異號 DIFF。$(-5, 2)$ 異號回傳 DIFF，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • x == 0 or y == 0：落在坐標軸上，回傳 "AXIS"。
  • x * y > 0：正正得正或負負得正，表示 $x$ 與 $y$ 正負號相同（第一象限與第三象限），回傳 "SAME"。
  • 否則（正負或負正）：$x$ 與 $y$ 異號（第二象限與第四象限），回傳 "DIFF"。
  • 代入 $(-5, 2)$：一負一正，坐標異號，回傳 "DIFF"。故選 (B)。
  1. 選項逐項診斷：
  • (A) 上半平面只看 $y > 0$，與 $x$ 無關，但本題使用的是 $x \times y > 0$。
  • (B) 乘積大於 0 表示同號（第一、三象限），小於 0 表示異號（第二、四象限）。$(-5) \times 2 = -10 < 0$，回傳 "DIFF"。
  • (C) 題目使用的是乘法 x * y > 0 而非加法。
  • (D) 程式完全未涉及絕對值比較。
  1. APCS 考場心法與常見陷阱：
  • 利用乘積符號判斷兩數同號（$x \cdot y > 0$）或異號（$x \cdot y < 0$）是數學與演算法的極簡技巧。
  • 將幾何分類抽成輔助函式，主程式只需對標籤進行比對處理。

Q-11-08-L02資料清洗管線與合法規格過濾 計算邏輯

對應 單元 11.8

下列程式印出 ['alice', 'john']。哪一句描述 pipeline 的資料處理規則，換成其他輸入也成立？

def clean_str(s):
    return s.strip().lower()

def is_valid_user(s):
    return len(s) >= 4 and s.isalpha()

def pipeline(raw_names):
    return [clean_str(x) for x in raw_names if is_valid_user(clean_str(x))]

names = ["  Alice ", "Bob", "Tom123", "   JOHN  "]
print(pipeline(names))
🎉 答對了！標準答案是 (C)
⚡ 速解

前後去空白轉小寫，過濾出長度 >= 4 且純英文字母的名稱。David 經處理後為 'david'，長度 5 且純字母，故回傳 ['david']，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 輔助函式 1 clean_str(s)：透過 .strip() 移除前後空白，並以 .lower() 轉成全小寫。
  • 輔助函式 2 is_valid_user(s)：len(s) >= 4 確保長度至少 4 位，s.isalpha() 確保全部為英文字母（剔除含有數字或特殊符號者，如 Tom123）。
  • pipeline 管線將輸入先清洗再驗證，僅合格者收錄。
  • 代入 [" David "]：清洗後為 "david"，長度為 5 且純字母，符合規格，回傳 ['david']。故選 (C)。
  1. 選項逐項診斷：
  • (A) "alice" 長度為 5 依然被保留，並非剛好等於 4；規則是至少為 4（>= 4）。
  • (B) 輸出是全小寫 ['alice', 'john']，且保留的是純英文字母。
  • (C) 依序經過 clean_str 清洗前後空白轉小寫，並透過 is_valid_user 驗證長度與純字母。
  • (D) 程式完全未涉及字串反轉或迴文判定。

  • 在 APCS 複雜字串處理實作題中，拆出清洗與驗證函式可以讓主流程一行完成，極具優雅與穩定性。
