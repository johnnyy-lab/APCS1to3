Q-10-01-R01逗號打包出來的東西 運行追蹤

對應 單元 10.1

下列 Python 程式執行後，畫面上印出的結果為何？

point = 4, 7
solo = 4,
print(point, solo * 2)
🎉 答對了！標準答案是 (C)
⚡ 速解

逗號會打包成元組。4, 7 是 (4, 7)。4, 是只有一個 4 的元組，乘 2 是再重複一次，得到 (4, 4)，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • point = 4, 7 沒有中括號，也沒有先寫小括號。逗號把 4 和 7 收成 (4, 7)。
  • solo = 4, 結尾的逗號表示「這是一個元素的元組」，不是整數 4。
  • 元組乘上整數是重複元素。solo * 2 是 (4, 4)，不是 8。
  • 印出 (4, 7) (4, 4)。故選 (C)。
  1. 選項逐項診斷：
  • (A) 把元組乘法當成元素自己相加。(4,) * 2 不會變成 (8,)。
  • (B) 這兩個都是小括號元組，不是中括號串列。
  • (C) 兩個逗號打包都成立，單元素再重複一次。
  • (D) 逗號沒有留在畫面上當一般文字。print 會把元組的括號一起印出來。
  1. APCS 考場心法與常見陷阱：
  • 小括號可以省略，逗號才是元組的標記。4, 7 與 (4, 7) 是同一種東西。
  • 單元素一定要看到那個逗號。沒有逗號的 (4) 只是整數 4。

Q-10-01-R02首格、倒數與前段 運行追蹤

對應 單元 10.1

下列 Python 程式執行後，畫面上印出的結果為何？

week = (3, 8, 1, 6)
print(week[0], week[-2], week[:2])
🎉 答對了！標準答案是 (A)
⚡ 速解

第 0 格是 3。從後面數，-1 是 6，-2 是 1。[:2] 只拿到下標 0 和 1，是 (3, 8)，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • week[0] 是 3。
  • 負索引從尾巴數。week[-1] 是 6，week[-2] 是 1。
  • week[:2] 到下標 2 之前停住，得到新元組 (3, 8)。原來的 week 沒有被改。
  • 印出 3 1 (3, 8)。故選 (A)。
  1. 選項逐項診斷：
  • (A) 首格、倒數第二格、前兩格，三個都對。
  • (B) 6 是 week[-1]，不是 week[-2]。
  • (C) 8 是下標 1。[:2] 不含下標 2 的 1，不會印出三個元素。
  • (D) 這是從下標 1 起算，把第 0 格漏掉了。
  1. APCS 考場心法與常見陷阱：
  • 元組的索引、負索引、切片和串列同一套。切片的右邊不包含。
  • 切片得到的是新元組，不是串列，也不會改到原來那一份。

Q-10-01-F01長度 1 再乘 2 程式填空

對應 單元 10.1

預期印出 1 ('go', 'go')。空格應填入哪一個？

word = ______
print(len(word), word * 2)
🎉 答對了！標準答案是 (D)
⚡ 速解

長度要是 1，乘 2 要變成兩個 'go'，而且外層是小括號。("go",) 才同時符合，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 目標：
  • len 是 1，所以裡面只有一個元素，不是兩個字元，也不是兩個元素。
  • 乘 2 之後印出 ('go', 'go')，外層是元組。
  • 故選 (D)。
  1. 選項逐項診斷：
  • (A) 沒有逗號，("go") 是字串。長度是 2，乘 2 變成 gogo。印出 2 gogo。
  • (B) 這是兩個元素。長度是 2，乘 2 變成 ('go', 'go', 'go', 'go')。
  • (C) 長度確實是 1，但乘 2 得到的是串列 ['go', 'go']。
  • (D) 逗號把 "go" 收成單元素元組。長度 1，乘 2 是 ('go', 'go')。
  1. APCS 考場心法與常見陷阱：
  • 小括號包住一個值時，身分由逗號決定。沒有逗號就只是把那個值括起來。
  • 字串的 len 數的是字元。元組的 len 數的是元素。

marks 裡每個元組都是 (列, 行)。預期印出 [[0, 0, 1], [0, 1, 0]]。空格應填入哪一個？

marks = [(0, 2), (1, 1)]
R, C = 2, 3
grid = [[0] * C for _ in range(R)]
for ______ in marks:
    grid[r][c] = 1
print(grid)
🎉 答對了！標準答案是 (B)
⚡ 速解

每個元組有兩個數，左邊也要兩個名字，而且列在前、行在後。(0, 2) 寫到第 0 列第 2 行，(1, 1) 寫到第 1 列第 1 行，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 兩格怎麼落：
  • (0, 2) 讓 grid[0][2] 變成 1。
  • (1, 1) 讓 grid[1][1] 變成 1。
  • 表是 [[0, 0, 1], [0, 1, 0]]。故選 (B)。
  1. 選項逐項診斷：
  • (A) 迴圈只做出 mark。下一行的 r 還沒有被指定，丟出 NameError: name 'r' is not defined。
  • (B) 左邊兩個名字對上列、行。
  • (C) 列和行對調。第一個元組變成 r 是 2，grid[2] 超出兩列，丟出 IndexError: list index out of range。
  • (D) 左邊三個名字，右邊只有兩個數，丟出 ValueError: not enough values to unpack (expected 3, got 2)。
  1. APCS 考場心法與常見陷阱：
  • (r, c) 的第一個數是列，第二個數是行。對調之後，界內的格子也會寫錯位置。
  • 左邊變數的個數要和元組的元素個數一樣。

Q-10-01-D01最後一行印出哪一份 測試除錯

想把第一格改成 5，並印出元組 (5, 2, 8)。現在印出的是 (1, 2, 8)。只改最後一行，哪一個改法會印出預期結果？

t = (1, 2, 8)
temp = list(t)
temp[0] = 5
print(t)
🎉 答對了！標準答案是 (A)
⚡ 速解

list(t) 做出另一份串列，t 自己仍是 (1, 2, 8)。5 寫在 temp 裡。要印元組，就得把 temp 再用 tuple 封回去，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 現況：
  • temp 一開始是 [1, 2, 8]，改完是 [5, 2, 8]。
  • t 沒有被指定過，仍是 (1, 2, 8)。
  • print(t) 因此印出舊元組。
  1. 選項逐項診斷：
  • (A) tuple(temp) 是 (5, 2, 8)。
  • (B) 數字對了，但印出的是串列 [5, 2, 8]。
  • (C) 這是在舊元組後面再接一個 5，印出 (1, 2, 8, 5)。第一格仍是 1。
  • (D) 與原程式相同，仍印出 (1, 2, 8)。
  1. APCS 考場心法與常見陷阱：
  • 直接寫 t[0] = 5 會丟出 TypeError: 'tuple' object does not support item assignment。
  • 要改內容，先 list 解凍，改完再 tuple 封回。原來的 t 不會自己跟著變。

Q-10-01-D02左邊只有兩個名字 測試除錯

對應 單元 10.1

想印出 9。現在一執行就發生 ValueError: too many values to unpack (expected 2)。只改解包那一行，哪一個改法會印出 9？

point = (3, 6, 1)
r, c = point
print(r + c)
🎉 答對了！標準答案是 (C)
⚡ 速解

元組有 3 個數，左邊只有 2 個名字，個數不合。[:2] 先取出 3 和 6，相加是 9，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 現況：
  • point 是 (3, 6, 1)，三個元素。
  • r, c = point 想一次接兩個，所以丟出 ValueError: too many values to unpack (expected 2)。
  • 程式走不到 print。
  1. 選項逐項診斷：
  • (A) 與原程式相同，仍是同一個 ValueError。
  • (B) point[1:] 是 (6, 1)。r + c 是 7，不是 9。
  • (C) point[:2] 是 (3, 6)。3 + 6 = 9。
  • (D) 左邊四個名字，右邊三個數，丟出 ValueError: not enough values to unpack (expected 4, got 3)。
  1. APCS 考場心法與常見陷阱：
  • 解包時，左邊變數個數必須等於右邊元素個數。多一個或少一個都會停住。
  • 這一題的 9 用的是前兩個數。切片的右邊不包含，[:2] 才是下標 0 和 1。

Q-10-01-P01同一格被寫入幾次 效能分析

對應 單元 10.1

下列程式執行時，grid[r][c] = 1 這一行執行幾次？

marks = [(0, 1), (2, 0), (1, 2), (0, 1)]
R, C = 3, 3
grid = [[0] * C for _ in range(R)]
for r, c in marks:
    grid[r][c] = 1
🎉 答對了！標準答案是 (D)
⚡ 速解

marks 有 4 個元組，迴圈就走 4 次。(0, 1) 出現兩次，第二次是再寫上同一個 1，仍然算一次執行，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 每一次寫入：
  • 四個元組依序是 (0, 1)、(2, 0)、(1, 2)、(0, 1)。
  • 每次都執行 grid[r][c] = 1，所以是 4 次。
  • 寫完之後，格子 1 只有 3 個。(0, 1) 的第二次沒有多造一格，但那一行還是跑了。
  1. 選項逐項診斷：
  • (A) 這是最後表上有幾個 1，不是這一行執行幾次。
  • (B) 這是整張 3 乘 3 的格子數。迴圈沒有走訪整張表。
  • (C) 重複的座標不是只算一次，更不是全題只寫一次。
  • (D) 一個元組就寫一次，四個元組寫四次。
  1. APCS 考場心法與常見陷阱：
  • 問的是某一行執行幾次時，重複座標要照迴圈次數算。
  • 問的是最後有幾格變成 1 時，同一格再寫一次仍然只算一格。

Q-10-01-P02內層迴圈實際轉了幾次 效能分析

對應 單元 10.1

下列程式執行時，total += 1 這一行執行幾次？

pts = [(0, 0), (2, 1), (1, 3)]
total = 0
for r, c in pts:
    for k in range(abs(r) + abs(c)):
        total += 1
🎉 答對了！標準答案是 (B)
⚡ 速解

(0, 0) 的距離是 0，內層不轉。(2, 1) 轉 3 次，(1, 3) 轉 4 次。3 + 4 = 7，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 三個點分開數：
  • abs(0) + abs(0) 是 0。range(0) 的迴圈一次都不進。
  • abs(2) + abs(1) 是 3，內層執行 3 次。
  • abs(1) + abs(3) 是 4，內層執行 4 次。
  • 合計 7 次。
  1. 選項逐項診斷：
  • (A) 這是外層的點數。外層跑 3 次，不代表內層那一行也是 3 次。
  • (B) 0 + 3 + 4。
  • (C) 只算了最後一個點的 4 次。
  • (D) 三個點再乘 3，程式沒有這樣轉。
  1. APCS 考場心法與常見陷阱：
  • 內層次數是每個點自己的 abs(r) + abs(c)，再全部相加。
  • 距離是 0 的點仍然會被外層拜訪一次，只是內層不執行。

Q-10-01-L01反轉接到另一個名字 計算邏輯

下列程式印出 (2, 9, 4) (4, 9, 2)。換成別的元組時，哪一句仍然成立？

t = (2, 9, 4)
s = t[::-1]
print(t, s)
🎉 答對了！標準答案是 (A)
⚡ 速解

印出的第一個仍是 (2, 9, 4)，反轉結果放在 s。切片沒有改到 t，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 這一組：
  • t[::-1] 從尾巴走回開頭，得到 (4, 9, 2)。
  • 這個新元組放進 s。print 的第一個值仍是原本的 t。
  • s 的型態還是元組，不是串列。
  1. 選項逐項診斷：
  • (A) 換成別的元組，反轉或切片都是做出新的一份。原來那個名字仍指向舊元組。
  • (B) 若 t 被倒過來，第一個印出的就會是 (4, 9, 2)。這一題不是。
  • (C) 元組不能對某一格指定。t[0] = 1 會丟出 TypeError: 'tuple' object does not support item assignment。
  • (D) 印出來的第二個值用小括號，是元組。串列才會是中括號。
  1. APCS 考場心法與常見陷阱：
  • 想留住舊順序，就把切片接到另一個名字。舊名字不用再指派。
  • 真的要改某一格，先轉成串列，改完再轉回元組。

Q-10-01-L02括號與逗號各做一件事 計算邏輯

對應 單元 10.1

下列程式印出 10 (5, 5)。換成別的整數 n 時，哪一句仍然成立？

a = (5)
b = (5,)
print(a * 2, b * 2)
🎉 答對了！標準答案是 (D)
⚡ 速解

(5) 是整數，乘 2 得 10。(5,) 是單元素元組，乘 2 是重複那個元素，得到 (5, 5)，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 這兩個寫法：
  • a = (5) 的括號只是把 5 括起來，a 是整數。a * 2 是 10。
  • b = (5,) 的逗號做出長度 1 的元組。b * 2 是 (5, 5)。
  • 印出 10 (5, 5)。
  1. 選項逐項診斷：
  • (A) (5) 有小括號，型態卻是整數。括號單獨不能決定型態。
  • (B) (5) 是整數。對它取 len 會丟出 TypeError: object of type 'int' has no len()，沒有長度 1。
  • (C) 這一題 (5) * 2 印出的是 10，不是 (5, 5)。
  • (D) 換成別的整數也一樣。沒有逗號就是那個整數；有逗號才是單元素元組，乘法是重複元素。
  1. APCS 考場心法與常見陷阱：
  • 單元素元組要寫成 (n,)，逗號留在括號裡面。
  • 整數乘法是數值相乘。元組乘法是把元素再排一次。

Q-10-02-R01三組元組比大小 運行追蹤

對應 單元 10.2

下列 Python 程式執行後，畫面上印出的結果為何？

print((4, 9) < (4, 3), (2, 80) < (3, 1), (1, 5) < (1, 5, 0))
🎉 答對了！標準答案是 (B)
⚡ 速解

元組從左邊比，第一格分出勝負就停。(4, 9) 與 (4, 3) 要看到 9 與 3，結果是 False。(2, 80) 第一格就小於 3，是 True。(1, 5) 是 (1, 5, 0) 的前段，較短的比較小，是 True。印出 False True True，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • (4, 9) < (4, 3)：第 0 格都是 4，改比第 1 格。9 不小於 3，所以是 False。
  • (2, 80) < (3, 1)：第 0 格 2 < 3，這一組成立。80 和 1 不會再比。
  • (1, 5) < (1, 5, 0)：前兩格都相同，左邊沒有第 3 格。共同前段一樣時，較短的元組比較小，所以是 True。
  • 印出 False True True。故選 (B)。
  1. 選項逐項診斷：
  • (A) 三組的真假都看反了。
  • (B) 第二格才分勝負、第一格就分勝負、前段相同時較短者較小，三個都對。
  • (C) 漏掉中間那組。2 已經小於 3，這一組是 True。
  • (D) 第一組 9 並沒有小於 3。第三組也不是 False。
  1. APCS 考場心法與常見陷阱：
  • 元組比大小是字典序。先比第 0 格，平手才比下一格。
  • 前面都相同、其中一邊先結束時，較短的那邊比較小。(1, 5) 小於 (1, 5, 0)。

Q-10-02-R02外層與內層一起拆 運行追蹤

下列 Python 程式執行後，畫面上印出的結果為何？

node = (7, (3, 8), "gate")
nid, (x, y), label = node
print(node[1], x, label)
🎉 答對了！標準答案是 (D)
⚡ 速解

node[1] 是整份內層 (3, 8)。巢狀解包讓 x 拿到 3、y 拿到 8，畫面上印的是 x 不是 y。label 是 gate。印出 (3, 8) 3 gate，秒選 (D)。

  1. 慢動作：
  • node 三格是 7、(3, 8)、"gate"。

  • (A) 7 是第 0 格的 nid。這一題第一個印的是 node[1]。
  • (B) (7, (3, 8)) 是前兩格，不是下標 1 那一格。
  • (C) 8 是 y。print 寫的是 x。
  • (D) 內層整份、內層第 0 格、最後的標籤，三個都對。
  1. APCS 考場心法與常見陷阱：
  • 左邊寫成 (x, y)，才會把內層元組再拆成兩個名字。
  • node[1] 與 node[1][0] 不同。前者是整份內層，後者才是裡面的第一格。

  • get(w, 0) 的 0 只是查詢時的臨時值，不會因此把鍵寫進字典。

Q-10-04-L01兩份鍵的順序 計算邏輯

對應 單元 10.4

下列程式印出 ['b', 'a'] ['a', 'b'] ['b', 'a']。換成別的字串鍵時，哪一句仍然成立？

rank = {"b": 2, "a": 5}
print(list(rank), list(sorted(rank)), list(rank))
🎉 答對了！標準答案是 (A)
⚡ 速解

第一份與第三份都是先 "b" 再 "a"，所以排序沒有改到原字典。中間那份才依字母變成 "a"、"b"。秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 印出的三份：
  • list(rank) 依放入順序，是 ['b', 'a']。直接走訪字典也是這個順序，走的是鍵。
  • sorted(rank) 把鍵另排成 ['a', 'b']。
  • 第三次再轉串列，仍是 ['b', 'a']。原字典沒被改。
  1. 選項逐項診斷：
  • (A) 放入順序與排序後的新串列是兩件事。換成別的字串鍵也一樣。
  • (B) 若原字典被改順序，第三份就會變成 ['a', 'b']。這一題不是。
  • (C) 走訪字典預設得到鍵。值要寫 rank.values()，或用 items() 同時拿。
  • (D) 這一題兩份的順序已經不同。只有鍵本來就由小到大時，兩份才會一樣。
  1. APCS 考場心法與常見陷阱：
  • sorted(d) 回傳鍵的新串列，不會把字典本身排好。
  • 要依鍵排序走訪，寫 for k in sorted(d)。原本的 for k in d 仍是放入順序。

Q-10-04-L02沒給預設的查詢 計算邏輯

對應 單元 10.4

下列程式印出 None 0。換成別的缺少的鍵時，哪一句仍然成立？

box = {"red": 4}
print(box.get("blue"), box.get("blue", 0))
🎉 答對了！標準答案是 (D)
⚡ 速解

沒寫預設就是 None，有寫 0 才是 0。None + 1 不能算。values() 也不是串列，不能直接 [0]。秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 這一列：
  • "blue" 不在字典裡。
  • get("blue") 交回 None。get("blue", 0) 交回 0。
  • 印出 None 0。字典裡仍只有 "red"。
  1. 選項逐項診斷：
  • (A) 會丟出 KeyError: 'blue' 的是 box["blue"]，不是 get。
  • (B) 0 是有寫預設才得到的。沒寫時印出的是 None。
  • (C) box.values()[0] 會丟出 TypeError: 'dict_values' object is not subscriptable。
  • (D) 換成別的缺少鍵也一樣。get 漏預設得到 None，再和整數相加就是那個 TypeError。視圖要先轉成串列才能用下標。
  1. APCS 考場心法與常見陷阱：
  • 計數時寫成 d.get(key) + 1，第一次就會因為 None 停住。要寫 d.get(key, 0) + 1。
  • get 的預設只影響這次回傳，不會自動把缺少的鍵建進字典。
