Q-90-02-R01連續從最前面離開兩次 運行追蹤

把串列當佇列：append 排到尾端，pop(0) 從最前面離開。下列程式印出哪兩行？

q.append(1)
q.append(2)
q.append(3)
print(q.pop(0))
print(q.pop(0))
🎉 答對了！標準答案是 (C)
⚡ 速解

1 最先排進去，所以最先離開，下一個是 2，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）

  • 三次 append 之後是 [1, 2, 3]，1 在最前面。

  1. 選項逐項診斷：

  • (B) 2 還沒輪到第一個離開。
  • (C) 先進來的先離開，順序是 1、2。
  • (D) 3 仍排在最後，這兩次都還輪不到。
  1. APCS 考場心法與常見陷阱：
  • 佇列看左端誰先到。pop() 不帶引數會改成拿右端，那就變成堆疊。

Q-90-02-R02偶數一進來最前面的人就離開 運行追蹤

對應 附錄・佇列

偶數放進佇列後，立刻讓最前面的人離開；奇數只排隊、不離開。結束時 q 是什麼？

    q.append(x)
    if x % 2 == 0:
        q.pop(0)
print(q)
🎉 答對了！標準答案是 (A)
⚡ 速解

2 自己進來又自己離開。5 留下。8 進來後離開的是 5，3 再排到 8 後面，剩下 [8, 3]，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 2 排入後是偶數，最前面的 2 離開，佇列回到 []。
  • 5 是奇數，佇列變成 [5]。
  • 8 排入後是 [5, 8]，偶數觸發 pop(0)，離開的是 5，剩下 [8]。
  • 3 是奇數，排到尾端，得到 [8, 3]。故選 (A)。
  1. 選項逐項診斷：
  • (A) 8 先留下，3 排在它後面。
  • (B) 忽略了偶數會讓隊首離開。
  • (C) 5 在 8 進來時已經離開。
  • (D) 最後的 3 沒有觸發離開，佇列不是空的。
  1. APCS 考場心法與常見陷阱：
  • 偶數觸發的是「最前面那個人離開」，不一定是剛剛進來的這個人。佇列裡已經有人時，先離開的是老人。

Q-90-02-P01四個人全部離開要做幾次 效能分析

print(left)
🎉 答對了！標準答案是 (B)
⚡ 速解

4 個人每人離開一次，left 印出 4。6 是後面的人被往前搬的格數，不是離開次數，秒選 (B)。

  • (A) 少算最後一個人。
  • (B) 離開次數等於人數。
  • (C) 3 + 2 + 1 = 6，那是被往前搬的格數。

  1. APCS 考場心法與常見陷阱：
  • 題目問「離開幾次」就數 pop(0) 執行幾次。問「被搬幾格」才把每次剩下的人數加起來。

Q-90-02-L02移到最後再讓下一個人離開 計算邏輯

對應 附錄・佇列

f(4) 得到 1，f(5) 得到 3。這個函式在做什麼？

def f(n):
    q = list(range(1, n + 1))
    while len(q) > 1:
        q.append(q.pop(0))
        q.pop(0)
    return q[0]
🎉 答對了！標準答案是 (A)
⚡ 速解

迴圈裡先把隊首送到尾端，再讓新的隊首離開。f(5) 留下 3，不是最大的 5，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • n = 5 時，佇列從 [1, 2, 3, 4, 5] 開始。
  • 1 移到最後，2 離開，剩下 [3, 4, 5, 1]。
  • 3 移到最後，4 離開，剩下 [5, 1, 3]。
  • 5 移到最後，1 離開，剩下 [3, 5]。
  • 3 移到最後，5 離開，剩下 [3]。故選 (A)。
  1. 選項逐項診斷：
  • (A) 兩行操作就是「隊首改排到最後」與「下一個離開」。
  • (B) f(4) 留下 1，f(5) 留下 3，都不是該輪最大編號。
  • (C) 回傳的是一個人的編號，不是整串排序結果。
  • (D) 若每次只做 pop(0)、不把人送到最後，n = 5 會留下 5，與題幹的 3 不符。
  1. APCS 考場心法與常見陷阱：
  • 同一輪有兩次隊首操作時，要分開記。先移走的人只是換到最後，下一次 pop(0) 才是真正離開。

  • (D) 人沒有減少，只是隊首換到隊尾。
  1. APCS 考場心法與常見陷阱：
  • append(pop(0)) 是移動，不是刪除。若題目要刪掉，就只能 pop(0)，不能再 append。

Q-90-02-L06先維持順序再整疊倒過來 計算邏輯

對應 附錄・佇列

f([1, 2, 3]) 得到 [3, 2, 1]，f([2, 1, 3]) 得到 [3, 1, 2]。這個函式在做什麼？

def f(a):
    q = []
    for x in a:
        q.append(x)
    s = []
    while q:
        s.append(q.pop(0))
    out = []
    while s:
        out.append(s.pop())
    return out
🎉 答對了！標準答案是 (A)
⚡ 速解

佇列先照原順序搬進堆疊，堆疊再從頂端倒出來。順序只被倒了一次。[2, 1, 3] 變成 [3, 1, 2]，不是排序，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • [2, 1, 3] 經佇列後仍是這個順序。
  • 放進堆疊時頂端變成 3。
  • 再從堆疊取出，得到 [3, 1, 2]。故選 (A)。
  1. 選項逐項診斷：
  • (A) 兩筆結果都是原順序反轉。
  • (B) [1, 2, 3] 沒有維持原樣。
  • (C) 回傳的是整串，不是只剩一項。
  • (D) [2, 1, 3] 排序後應是 [1, 2, 3]，不是 [3, 1, 2]。
  1. APCS 考場心法與常見陷阱：
  • 佇列搬運不改變順序，堆疊再搬一次才會反轉。兩邊都用堆疊，就會反轉兩次，順序回到原樣。
