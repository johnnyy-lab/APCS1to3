D05解析

答案 (A)

這是兩個獨立的 if。x 是 12 時兩個條件都成立，所以印 1 又印 2。第二個改成 elif 之後，第一個成立就不再看後面。x 為 7 時第一個不成立、第二個成立，印 2。x 為 3 時走 else，印 3。

(B) x 為 12 時仍印 1 和 2。x 為 3 時兩個條件都不成立，什麼都不印。
(C) 兩個條件都變成 x > 5。x 為 12 時仍印兩行。
(D) x 為 12 時兩行都印 2。

執行結果：

三個 x 各跑一次。只有 (A) 分別印出 1、2、3。

- (A) x=12 → 1；x=7 → 2；x=3 → 3
- (B) x=12 → 1 / 2；x=7 → 2；x=3 → 沒有輸出
- (C) x=12 → 1 / 2；x=7 → 1 / 2；x=3 → 3
- (D) x=12 → 2 / 2；x=7 → 2；x=3 → 3
