Q-90-02-R01連續從最前面離開兩次 運行追蹤

對應 附錄・佇列

把串列當佇列：append 排到尾端，pop(0) 從最前面離開。下列程式印出哪兩行？

q = []
q.append(1)
q.append(2)
q.append(3)
print(q.pop(0))
print(q.pop(0))
🎉 答對了！標準答案是 (C)
⚡ 速解

1 最先排進去，所以最先離開，下一個是 2，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 三次 append 之後是 [1, 2, 3]，1 在最前面。
  • 第一次 pop(0) 拿走 1，剩下 [2, 3]。
  • 第二次拿走 2。故選 (C)。
  1. 選項逐項診斷：
  • (A) 那是從右端拿的順序，這題拿的是左端。
  • (B) 2 還沒輪到第一個離開。
  • (C) 先進來的先離開，順序是 1、2。
  • (D) 3 仍排在最後，這兩次都還輪不到。
  1. APCS 考場心法與常見陷阱：
  • 佇列看左端誰先到。pop() 不帶引數會改成拿右端，那就變成堆疊。

Q-90-02-R02偶數一進來最前面的人就離開 運行追蹤

對應 附錄・佇列

偶數放進佇列後，立刻讓最前面的人離開；奇數只排隊、不離開。結束時 q 是什麼？

q = []
for x in [2, 5, 8, 3]:
    q.append(x)
    if x % 2 == 0:
        q.pop(0)
print(q)
🎉 答對了！標準答案是 (A)
⚡ 速解

2 自己進來又自己離開。5 留下。8 進來後離開的是 5，3 再排到 8 後面，剩下 [8, 3]，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 2 排入後是偶數，最前面的 2 離開，佇列回到 []。
  • 5 是奇數，佇列變成 [5]。
  • 8 排入後是 [5, 8]，偶數觸發 pop(0)，離開的是 5，剩下 [8]。
  • 3 是奇數，排到尾端，得到 [8, 3]。故選 (A)。
  1. 選項逐項診斷：
  • (A) 8 先留下，3 排在它後面。
  • (B) 忽略了偶數會讓隊首離開。
  • (C) 5 在 8 進來時已經離開。
  • (D) 最後的 3 沒有觸發離開，佇列不是空的。
  1. APCS 考場心法與常見陷阱：
  • 偶數觸發的是「最前面那個人離開」，不一定是剛剛進來的這個人。佇列裡已經有人時，先離開的是老人。

Q-90-02-F01讓 1 先離開 程式填空

對應 附錄・佇列

想先印出 1，再印出 [2, 3]。空格應填哪一個？

q = [1, 2, 3]
print(______)
print(q)
🎉 答對了！標準答案是 (D)
⚡ 速解

1 在最前面。pop(0) 會印出 1，並把剩下的兩項留成 [2, 3]，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • pop(0) 回傳 1，串列變成 [2, 3]。
  • 兩行輸出都符合題目。故選 (D)。
  1. 選項逐項診斷：
  • (A) pop() 印出 3，剩下 [1, 2]。
  • (B) q[-1] 印出 3，而且串列完全沒變。
  • (C) remove(3) 回傳 None，剩下 [1, 2]。
  • (D) 從索引 0 拿走，正好是隊首 1。
  1. APCS 考場心法與常見陷阱：
  • 佇列的離開端是索引 0。不寫引數的 pop() 離開的是另一端。

Q-90-02-F02讓最先排進去的人先被印出 程式填空

對應 附錄・佇列

兩個呼叫都用同一種排法。想讓 pop(0) 印出 1。空格應填哪一組？

q = []
______
______
print(q.pop(0))
🎉 答對了！標準答案是 (B)
⚡ 速解

兩次都從尾端排，1 會停在最前面，pop(0) 印出 1，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • append(1) 再 append(2)，串列是 [1, 2]。
  • pop(0) 拿走 1。故選 (B)。
  1. 選項逐項診斷：
  • (A) 兩次都插到最前面，2 後插入，串列變成 [2, 1]，印出 2。
  • (B) 1 先排、2 排到後面，隊首仍是 1。
  • (C) 隊首變成 2，印出 2。
  • (D) insert(0, 2) 把 2 插到 1 前面，印出 2。
  1. APCS 考場心法與常見陷阱：
  • 佇列只從尾端進。插到索引 0 會插隊，先進的人就不再先出。

Q-90-02-D01想保持進來的順序卻從右端拿 測試除錯

對應 附錄・佇列

想依進來的順序得到 [1, 2, 3]。現在印出 [3, 2, 1]。只改一處，哪一個改法會得到 [1, 2, 3]？

q = []
for x in [1, 2, 3]:
    q.append(x)
out = []
while q:
    out.append(q.pop())
print(out)
🎉 答對了！標準答案是 (A)
⚡ 速解

人是從尾端排進去的，卻從尾端被拿走，順序就倒了。改成 pop(0) 才從最前面離開，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 排完是 [1, 2, 3]。
  • pop() 依序拿走 3、2、1。
  • 改成 pop(0) 後依序拿走 1、2、3。故選 (A)。
  1. 選項逐項診斷：
  • (A) 離開端改到最前面，順序與進來時相同。
  • (B) if 只拿一次，out 變成 [3]。
  • (C) 這三個數本來就由小到大，排序後 pop() 仍從 3 開始拿。
  • (D) q[0] 不會把人移出佇列，while q 永遠不結束。
  1. APCS 考場心法與常見陷阱：
  • 只看隊首卻不把人移走，迴圈的條件就不會改變。離開一定要真正刪掉那一項。

Q-90-02-D02隊空了還繼續叫下一個人 測試除錯

對應 附錄・佇列

佇列裡只有甲、乙。前兩行可以印出這兩個人，第三行在隊空時要印 空，不能發生 IndexError。只改第三個 print，哪一個改法符合要求？

q = []
q.append("甲")
q.append("乙")
print(q.pop(0))
print(q.pop(0))
print(q.pop(0))
🎉 答對了！標準答案是 (D)
⚡ 速解

前兩次已經把甲、乙送走。第三次要先看佇列還有沒有人，沒有就印 空，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 兩次 append 之後是 ["甲", "乙"]。
  • 前兩個 pop(0) 印出甲、乙，佇列變成 []。
  • 空串列再 pop(0) 會發生 IndexError。
  • (D) 先判斷 q 是空的，改印 空。故選 (D)。
  1. 選項逐項診斷：
  • (A) 空串列呼叫 pop() 一樣是 IndexError。
  • (B) 會印出丙，題目要的是隊空時印 空。
  • (C) 空串列讀 q[0] 仍是 IndexError。
  • (D) 有人才離開，沒有人就印 空。
  1. APCS 考場心法與常見陷阱：
  • 離開之前先看長度。pop 與 q[0] 都不會在空隊伍時自動印出替代文字。

Q-90-02-P01四個人全部離開要做幾次 效能分析

對應 附錄・佇列

4 個人依序進來，再依序全部從最前面離開。離開這個動作執行幾次？

q = [1, 2, 3, 4]
left = 0
while q:
    q.pop(0)
    left += 1
print(left)
🎉 答對了！標準答案是 (B)
⚡ 速解

4 個人每人離開一次，left 印出 4。6 是後面的人被往前搬的格數，不是離開次數，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • while 每轉一圈就有一個人離開，left 加 1。
  • 4 個人所以轉 4 圈，印出 4。故選 (B)。
  1. 選項逐項診斷：
  • (A) 少算最後一個人。
  • (B) 離開次數等於人數。
  • (C) 3 + 2 + 1 = 6，那是被往前搬的格數。
  • (D) 4 + 3 + 2 + 1 = 10，把離開的人自己也算成一格搬動。
  1. APCS 考場心法與常見陷阱：
  • 題目問「離開幾次」就數 pop(0) 執行幾次。問「被搬幾格」才把每次剩下的人數加起來。

Q-90-02-P02五個人時隊首離開要搬幾格 效能分析

對應 附錄・佇列

q 裡有 5 個人，最前面的人離開一次。後面剩下的人一共要往前挪幾格？

q = [1, 2, 3, 4, 5]
q.pop(0)
🎉 答對了！標準答案是 (C)
⚡ 速解

被拿走的是第 1 個，剩下 4 個都要往前一格，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • pop(0) 刪掉 1。
  • 2、3、4、5 各往前補一格，共 4 格。
  • 串列變成 [2, 3, 4, 5]。故選 (C)。
  1. 選項逐項診斷：
  • (A) 1 只代表這一次離開，不是被搬動的人數。
  • (B) 5 把已經離開的那個人也算進去了。
  • (C) 原本人數減 1，就是要挪動的格數。
  • (D) 從中間或右端拿才可能不用搬左方；從索引 0 拿，右方一定要搬。
  1. APCS 考場心法與常見陷阱：
  • 人數是 n 時，從最前面離開一次要搬 n - 1 格。從最後面 pop() 離開則是 0 格。

Q-90-02-L01這個函式回傳的串列是什麼 計算邏輯

對應 附錄・佇列

f([1, 2, 3, 4]) 得到 [1, 2, 3, 4]，f([3, 1, 2]) 得到 [3, 1, 2]。這個函式在做什麼？

def f(a):
    q = []
    for x in a:
        q.append(x)
    out = []
    while q:
        out.append(q.pop(0))
    return out
🎉 答對了！標準答案是 (D)
⚡ 速解

從尾端排進去、再從最前面依序搬出來，順序跟原來一樣。[3, 1, 2] 沒有被排序，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • [3, 1, 2] 排入後仍是 [3, 1, 2]。
  • pop(0) 依序拿到 3、1、2。
  • 回傳值與原串列相同，但是另一個新串列。故選 (D)。
  1. 選項逐項診斷：
  • (A) 倒序會把 [3, 1, 2] 變成 [2, 1, 3]。
  • (B) 排序會把 [3, 1, 2] 變成 [1, 2, 3]。
  • (C) 兩筆例子都沒有重複值，也看不出刪除。
  • (D) 每一項都還在，位置也沒變。
  1. APCS 考場心法與常見陷阱：
  • 一端進、另一端出，順序保持不變。兩端都在右端，順序才會倒過來。

Q-90-02-L02移到最後再讓下一個人離開 計算邏輯

對應 附錄・佇列

f(4) 得到 1，f(5) 得到 3。這個函式在做什麼？

def f(n):
    q = list(range(1, n + 1))
    while len(q) > 1:
        q.append(q.pop(0))
        q.pop(0)
    return q[0]
🎉 答對了！標準答案是 (A)
⚡ 速解

迴圈裡先把隊首送到尾端，再讓新的隊首離開。f(5) 留下 3，不是最大的 5，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • n = 5 時，佇列從 [1, 2, 3, 4, 5] 開始。
  • 1 移到最後，2 離開，剩下 [3, 4, 5, 1]。
  • 3 移到最後，4 離開，剩下 [5, 1, 3]。
  • 5 移到最後，1 離開，剩下 [3, 5]。
  • 3 移到最後，5 離開，剩下 [3]。故選 (A)。
  1. 選項逐項診斷：
  • (A) 兩行操作就是「隊首改排到最後」與「下一個離開」。
  • (B) f(4) 留下 1，f(5) 留下 3，都不是該輪最大編號。
  • (C) 回傳的是一個人的編號，不是整串排序結果。
  • (D) 若每次只做 pop(0)、不把人送到最後，n = 5 會留下 5，與題幹的 3 不符。
  1. APCS 考場心法與常見陷阱：
  • 同一輪有兩次隊首操作時，要分開記。先移走的人只是換到最後，下一次 pop(0) 才是真正離開。
