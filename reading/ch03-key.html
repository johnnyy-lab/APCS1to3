Q-03-01-R01浮點數向零截斷（Truncation towards Zero）特性追蹤 運行追蹤

答案 (C)

⚡ 速解

int() 轉型為整數時不是四捨五入，也不是像 // 向下取整，而是「無條件向零截斷（丟棄小數點後所有數位）」。因此正數 7.9 變成 7，負數 -7.9 變成 -7。兩者相減 7 - (-7) = 14。秒選 (C) 7 -7 14。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. int() 截斷機制（Truncation towards Zero）：
  • 在 Python 中，將浮點數傳入 int() 函式進行強制轉型時，直譯器採用的策略是「向零靠攏截斷（Truncate towards Zero）」，直接切除小數點後方的所有數位。
  • 對於正浮點數 pos = 7.9：截斷小數 .9 後得到整數 7，故 a = 7。
  • 對於負浮點數 neg = -7.9：截斷小數 .9 後向零靠攏得到整數 -7（絕非向下取整的 -8），故 b = -7。
  • 計算差值：diff = a - b = 7 - (-7) = 7 + 7 = 14。
  • 最終輸出：print(a, b, diff) 輸出 7 -7 14。故選 (C)。
  1. 經典陷阱與對比（int() vs // 地雷對照）：
  • 地雷一（誤以為四捨五入）：誤以為 7.9 會四捨五入成 8、-7.9 變成 -8，因而誤選 (B)。Python 的 int() 絕不做四捨五入！
  • 地雷二（混淆 int() 與整數除法 //）：整數除法運算子 // 是「向下取整（Floor Division，向負無窮大方向取整）」，例如 -7.9 // 1 結果為 -8.0；但 int(-7.9) 是「向零截斷」，結果為 -7。考生極易混淆兩者而誤選 (A)。
  1. APCS 考場心法：
  • 數線心智模型：想像數線上的 0 是磁鐵，int() 一律將數值「往 0 的方向拉動」直到最近的整數。正數縮小（7.9 → 7），負數變大（-7.9 → -7）。

Q-03-02-R01大小寫差值 32（ASCII 編碼）與字元連續性追蹤 運行追蹤

答案 (D)

⚡ 速解

大寫字母 'A' 的 ASCII 碼是 65，'G' 是第 7 個字母（$65 + 6 = 71$）。ASCII 中同一個英文字母的大寫與小寫編碼差值恰好固定為 32，故 code2 = 71 + 32 = 103，對應小寫字母 'g'。秒選 (D) 71 103 g。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. ASCII 編碼核心結構與數值連續性：
  • 在 ASCII 編碼表中，大寫英文字母 'A'～'Z' 的編碼是連續的整數區間：65 到 90。
  • 小寫英文字母 'a'～'z' 的編碼同樣連續：97 到 122。
  • 觀察兩者的差值：$97 - 65 = 32$（十六進位 0x20）。對於任何英文字母，其小寫字元的 ASCII 碼恆等於大寫字元的 ASCII 碼加上 32。
  1. 程式執行流程逐行慢動作拆解：
  • 第 1～2 行：c1 = "G"，呼叫 ord("G") 取得字元 'G' 的 ASCII 編碼。因為 'A' 是 65，'G' 往後數 6 位：$65 + 6 = 71$，故 code1 = 71。
  • 第 3 行：code2 = code1 + 32 = 71 + 32 = 103。
  • 第 4 行：chr(103) 將整數編碼 103 轉換回字元。因為 'a' 是 97，往後數 6 位：$97 + 6 = 103$，正是小寫字元 'g'，故 c2 = "g"。
  • 第 5 行：印出 code1, code2, c2，輸出為 71 103 g。故選 (D)。
  1. 選項逐項診斷：
  • (A) 65 97 g：誤將變數 'G' 當成了首個字母 'A'（65）。
  • (B) 71 103 G：計算出數值 103 卻誤以為轉回的依然是大寫 'G'。
  • (C) 72 104 g：字母位移算錯（誤將 G 當成第 8 個字母差 7）。

Q-03-04-L01奇數位與偶數位數字總和差距之純數學絕對值邏輯解析 計算邏輯

答案 (C)

⚡ 速解

千位是 8、十位是 5，奇數位總和 8 + 5 = 13。百位是 3、個位是 2，偶數位總和 3 + 2 = 5。兩者差值絕對值 abs(13 - 5) = 8。輸出 13 5 8。秒選 (C) 13 5 8。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 位數剝皮提取：
  • d1 = 8352 // 1000 = 8（千位數）。
  • d2 = (8352 // 100) % 10 = 83 % 10 = 3（百位數）。
  • d3 = (8352 // 10) % 10 = 835 % 10 = 5（十位數）。
  • d4 = 8352 % 10 = 2（個位數）。
  1. 群組加總與差距計算：
  • 奇數位總和：odd_pos_sum = d1 + d3 = 8 + 5 = 13。
  • 偶數位總和：even_pos_sum = d2 + d4 = 3 + 2 = 5。
  • 無向差距：diff = abs(13 - 5) = abs(8) = 8。
  • 印出 odd_pos_sum, even_pos_sum, diff，輸出為 13 5 8。故選 (C)。
  1. 延伸演算法背景（11 的倍數法則）：
  • 若一個整數的奇數位和與偶數位和的差值是 11 的倍數（差值 % 11 == 0），則該整數必為 11 的倍數。本題為該演算法最核心的特徵提取步驟。

Q-03-04-L02三數環形相鄰差值總和與對稱不變性邏輯解析 計算邏輯

答案 (B)

⚡ 速解

三點排序後為 14, 29, 48。全距 48 - 14 = 34。環形走一圈就像從最低點 14 走到最高點 48 又走回 14，總路程恆等於全距的 2 倍：34 * 2 = 68！輸出 68 34。秒選 (B) 68 34。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 各段物理距離逐一計算：
  • d_ab = abs(14 - 48) = abs(-34) = 34。
  • d_bc = abs(48 - 29) = abs(19) = 19。
  • d_ca = abs(29 - 14) = abs(15) = 15。
  • 環形總和：total_cycle = 34 + 19 + 15 = 68。
  1. 全距計算：
  • 最大值：max(14, 48, 29) = 48。
  • 最小值：min(14, 48, 29) = 14。
  • 全距：span = 48 - 14 = 34。
  1. 數學幾何不變性（Geometric Invariance）：
  • 設三點大小順序為 $L < M < H$。
  • 環形總距離為：

$$|L - M| + |M - H| + |H - L| = (M - L) + (H - M) + (H - L) = 2(H - L)$$

  • 換言之，中間點 $M$ 的具體位置完全被抵銷消去，環形差值總和恆為全距的 2 倍！
  • 輸出為 68 34。故選 (B)。
