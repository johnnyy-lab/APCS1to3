D05第二個條件不該再進來

對應 5.5

規則是：x 大於 10 只印 1；大於 5 且不超過 10 只印 2；其餘只印 3。現在 x 是 12，卻印出兩行。哪一個改法能讓 x 為 12、7、3 時，分別只印 1、2、3？

x = 12
if x > 10:
    print(1)
if x > 5:
    print(2)
else:
    print(3)
  1. (A) 把第二個 if 改成 elif
  2. (B) 刪掉 else 和 print(3)
  3. (C) 把 x > 10 改成 x > 5
  4. (D) 把 print(1) 改成 print(2)

D10奇偶寫反

想加 1 到 5 的奇數，印出 9。現在印出 6。哪一個改法會印出 9？

total = 0
for i in range(1, 6):

        continue
    total += i
print(total)
  1. (A) 把 i % 2 == 1 改成 i % 2 == 0
  2. (B) 把 i % 2 == 1 改成 i % 2 == 2
  3. (C) 把 continue 改成 break
  4. (D) 把 range(1, 6) 改成 range(1, 5)
