  • 第 3 行：傳入 "Sum:" 與 x + y（10 + 20 = 30），兩者之間以空格分開，印出 Sum: 30 並自動換行。

⚡ 速解

單等號 = 在 Python 中為「賦值/指定運算子（Assignment Operator）」或關鍵字引數賦值。在運算式 x // y = ... 中左側不是合法變數名，會引發 SyntaxError: expression cannot contain assignment。欲輸出等號算式，必須把標籤用引號括起當作字串："x // y ="。秒選 (C)。

  • 初學者經常將數學上的「等式展示」與程式中的「變數賦值」混淆。

SyntaxError: expression cannot contain assignment, perhaps you meant "=="?

  • 只要將欲呈現在畫面上的算式文字與等號使用字串引號包起來即可：

  1. 錯誤選項逐項診斷：
  • (A) 除數 y = 3 != q 0，不會發生除以零錯誤。
  • (B) 重複變數在直譯器中完全合法，錯誤並非來自變數命名。

在 Python 3 中，map() 回傳的是一個惰性求值的 map 迭代器物件（Iterator）。考慮下列程式碼：

# 嘗試第二次解包

⚡ 速解

map() 是單向流動的「一次性迭代器（Iterator）」。第一次解包 a, b = m 已經把裡面的所有元素「抽乾消耗殆盡」；第二次再去解包它時，裡面已經是空的（0 個元素），因此引發 ValueError: not enough values to unpack (expected 2, got 0)。秒選 (C)。

  • 當執行 c, d = m 時，直譯器再次向 m 索取元素，但 m 已經無法提供任何新元素（元素數量為 0）。
  • 左側預期接收 2 個變數，右側卻只有 0 個元素，直譯器立刻拋出：

ValueError: not enough values to unpack (expected 2, got 0)

  1. 錯誤選項逐項診斷：
  • (A) 誤以為 map 物件會像串列（list）一樣可以反覆重複讀取。若要重複讀取，必須轉為串列儲存。
  • (B) Python 不會自動填入預設值 0。
  • (D) 錯誤型態是 ValueError，非 TypeError。故選 (C)。

Q-04-07-L02分三行讀入兩回合比分與加權積分邏輯推演 計算邏輯

對應 單元 4.7

機器人競賽分為兩回合，計分規則為：計算每回合的「淨勝分（得分 - 失分）」，且第二回合為主場比賽，其淨勝分享有加權乘數。測資分三行輸入：
- 第 1 行：第一回合的得分與失分（整數 S_1, L_1）
- 第 2 行：第二回合的得分與失分（整數 S_2, L_2）
- 第 3 行：第二回合的加權倍率（整數 W）

# 測資分 3 行輸入：
# 85 70
# 90 80
# 2
s1, l1 = map(int, input().split())
s2, l2 = map(int, input().split())
weight = int(input())

net1 = s1 - l1
net2 = s2 - l2
total_score = net1 + net2 * weight

print("Score:", total_score)

當依序輸入 85 70、90 80 與 2 後，終端機畫面上印出的結果為何？

⚡ 速解

第一回合淨勝分為 85 - 70 = 15；第二回合淨勝分為 90 - 80 = 10。總積分為 15 + 10 * 2 = 15 + 20 = 35。輸出 Score: 35。秒選 (D)。
