Q-05-01-R01運算子優先級：先算術運算再進行大小比較追蹤 運行追蹤

對應 單元 5.1

下列 Python 程式執行後，終端機畫面上印出的布林值結果為何？

x = 5
y = 3
ans1 = x + y * 2 > 10
ans2 = x * 2 == y + 7
print(ans1, ans2)
🎉 答對了！標準答案是 (C)
⚡ 速解

牢記優先級鐵律：「先乘除、後加減、最後比大小」。ans1 先算 3 * 2 = 6，加 5 得 11，11 > 10 為 True；ans2 先算兩端乘除與加法 5 * 2 = 10 及 3 + 7 = 10，10 == 10 為 True。兩者皆真。秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 運算子優先級（Operator Precedence）層級體系：
  • 在 Python 表達式中，各類運算子的結合順序有嚴格的高低層級：
  • 高階：乘除算術運算子（*, /, //, %）
  • 次高：加減算術運算子（+, -）
  • 中階：比較運算子（>, <, >=, <=, ==, !=）
  • 低階：賦值運算子（=）
  1. 逐步推演驗證：
  • 第 3 行：ans1 = x + y * 2 > 10
  • 先算乘法：y * 2 = 3 * 2 = 6。
  • 再算加法：x + 6 = 5 + 6 = 11。
  • 最後進行大於比較：11 > 10，條件成立，回傳布林值 True。
  • 第 4 行：ans2 = x * 2 == y + 7
  • 左側算術求值：x * 2 = 5 * 2 = 10。
  • 右側算術求值：y + 7 = 3 + 7 = 10。
  • 執行相等比較：10 == 10，條件成立，回傳布林值 True。
  • 第 5 行以空格隔開印出 True True。
  1. 錯誤選項逐項診斷：
  • (A) 誤以為 ans1 是由左至右先加後乘（(5 + 3) * 2 = 16），但判斷為 False 則是算術錯誤。
  • (B) 誤以為 ans2 兩邊不等。
  • (D) 兩者皆真，不可能皆為 False。故選 (C)。

對應 單元 5.1

Python 支援數學風格的「連續比較式（Chained Comparisons）」。觀察下列程式碼：

a = 15
b = 15
c = 15
x = 8

res1 = a == b == c
res2 = 5 < x < 10 <= a
res3 = 10 < x < 20

print(res1, res2, res3)

執行這段程式後，終端機畫面上印出的完整內容為何？

🎉 答對了！標準答案是 (A)
⚡ 速解

連續比較等價於隱含的「且（AND）」連接。res1 三者皆為 15（True）；res2 中 5 < 8 < 10 <= 15 全程遞增成立（True）；res3 中 10 < 8 首關即不成立（False）。輸出 True True False。秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 連續比較式語法糖（Syntactic Sugar）：
  • 在 C/C++ 或 Java 中，5 < x < 10 會先計算 5 < x 得 1，再拿 1 < 10 比較，產生違背直覺的結果。
  • 但在 Python 中，連續比較被嚴格實作為連鎖邏輯：
  • a == b == c 等價於 (a == b) and (b == c)。因為 15 == 15 且 15 == 15 皆為真，res1 為 True。
  • 5 < x < 10 <= a 等價於 (5 < x) and (x < 10) and (10 <= a)。代入 x=8, a=15，三者分別為 5 < 8（真）、8 < 10（真）、10 <= 15（真），全體皆真，res2 為 True。
  • 10 < x < 20 等價於 (10 < x) and (x < 20)。第一項 10 < 8 即為假，res3 為 False。
  1. 錯誤選項逐項診斷：
  • (B) 誤以為 res3 中 x < 20 成立整串就成立，忽略了第一段 10 < 8 違背。
  • (C) 誤以為多等號比較 a == b == c 語法錯誤或回傳 False。
  • (D) 連續比較是 Python 的獨家原生核心特性，絕非語法錯誤。故選 (A)。

SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

  • 欲進行數值相等比較，必須使用比較運算子雙等號：

  1. 錯誤選項逐項診斷：
  • (A) 這是編譯時期的語法結構錯誤（SyntaxError），並非執行時期的型態錯誤（TypeError）。
  • (B) 誤將 C 語言（賦值表達式回傳右側值）的特性套用至 Python。

  • 在布林代數中，「否定交集」等價於「補集的聯集」：

not (A and B) <=> (not A) or (not B)

  1. 逐步代入推演：
  • 第 5 行：res1 = not (a > 0 and b < 10)
  • a = 5 > 0 為 True。
  • b = 12 < 10 為 False。

  • 第三關（XOR 互斥或運算）：

  • True == False 條件不成立，略過。
