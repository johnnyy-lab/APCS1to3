  • 計算過程：10.0 + 2.0 = 12.0。
  • 變數 c 參照浮點數物件 12.0，type(c).__name__ 為字串 'float'。
  • print(type(c).__name__, c) 輸出 float 12.0。故選 (A)。
  1. 經典陷阱剖析：

  • (C) 誤以為浮點數印出時若無小數會省略 .0（Python 的 float 印出時一定至少有一位小數）。

🎉 答對了！標準答案是 (A)
⚡ 速解

type(x) 是整數 int，type(y) 是浮點數 float，兩者類別不同，前者比較為 False；但數值比較 5 == 5.0 在數值大小上完全相等，後者為 True。秒選 (A) False True。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 型態比對與數值比較的本質差異：
  • 型態比對 type(x) == type(y)：
  • type(5) 回傳 <class 'int'>。
  • type(5.0) 回傳 <class 'float'>。
  • 兩者指向不同的型態物件，故比對結果為 False。
  • 數值比較 x == y：
  • Python 支援跨型態數值比較（Numeric Equality）。在比對 5 == 5.0 時，直譯器會將兩者在數值軸上對齊，數學上 5 與 5.0 數值相等，故回傳 True。
  • 第 3 行印出 False True。故選 (A)。
  1. APCS 考場重點：
  • 數值相等不代表型態相同！在字典（dict）或集合（set）中，因為 hash(5) == hash(5.0) 且 5 == 5.0，5 與 5.0 會被視為相同鍵值（Key Collision），這是高頻進階考點。

a = 5
b = 3
avg = (a + b) / 2
print(avg)

🎉 答對了！標準答案是 (A)

斜線除法 / 必定產生浮點數 4.0，利用 Python 浮點數內建的 avg.is_integer() 判斷小數是否為 0，若為真則轉成 int(avg) 印出 4，否則保留原小數。秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）

  • (C) 若數值為 10.05，字串替換會誤把 10.05 變成 15，造成嚴重災難。
  • (D) round(4.5) 會把小數四捨五入抹殺。

Q-02-01-D02浮點數精度極限與二進位捨入誤差除錯 測試除錯

對應 單元 2.1

下列 Python 程式執行後，畫面上印出的結果為何？背後成因為何？

x = 0.1 + 0.2
if x == 0.3:
    print("Equal")
else:
    print("Not Equal")
🎉 答對了！標準答案是 (A)
⚡ 速解

電腦科學界的經典常識：在二進位浮點數標準（IEEE 754）中，0.1 與 0.2 都是無窮循環小數，相加後等於 0.30000000000000004，絕對不等於 0.3，因此印出 Not Equal。秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. IEEE 754 二進位浮點數限制：
  • 人類慣用十進位（分母為 10 的因數 2 與 5 才能除盡，如 $1/2 = 0.5$、$1/5 = 0.2$、$1/10 = 0.1$）。
  • 但電腦硬體是二進位（分母只能是 2 的次方才能除盡，如 $1/2 = 0.5$、$1/4 = 0.25$、$1/8 = 0.125$）。
  • 十進位的 0.1 在二進位中是無限循環小數：$0.0001100110011..._2$。
  • 在 53 位元尾數長度限制下被迫截斷，因此 0.1 + 0.2 在記憶體中的實際數值是 0.30000000000000004。
  • 執行 0.30000000000000004 == 0.3 結果為 False，進入 else 區塊印出 Not Equal。故選 (A)。
  1. 工程防範方案：
  • 若需要比較兩浮點數是否相等，絕不可直接用 ==，應使用 math.isclose(a, b) 或 abs(a - b) < 1e-9。

⚡ 速解

先乘除後加減！乘法 4 * 3 = 12，整除 6 // 2 = 3。算式簡化為 20 - 12 + 3。加減同級由左至右算：20 - 12 = 8，8 + 3 = 11。秒選 (A) 11。

  • 在 Python 中，乘除運算子（*、/、//、%）的優先級高於加減運算子（+、-）。

  • 6 // 2 整除計算得到 3。
  • 第二階段（加減運算與左結合性）：
  • 加法與減法具備相同的優先級，依照「由左至右結合（Left-to-Right Associativity）」規則依序運算。
  • 先算左側減法：20 - 12 = 8。
  • 再算右側加法：8 + 3 = 11。
  • 變數 ans 被賦值為整數 11，印出 11。故選 (A)。
  1. 經典陷阱診斷：
  • (B) 27：誤以為由左至右平鋪直敘計算（20 - 4 = 16，16 * 3 = 48...）。

  • 若 $\text{exp} = 10^6$，寫法甲計算 base ** exp 會產生數十萬個二進位位元的大整數，乘法運算複雜度飆升，極易觸發 Python 3.11+ 的大數轉型限制（ValueError: Exceeds the limit for integer string conversion）。
  • 寫法乙使用三參數 pow(base, exp, mod)，底層以二進位分解指數（平方法），每次相乘後立刻對 mod 模除，數字永遠維持在 $0 \sim \text{mod}-1$ 之間，運算瞬間完成（小於 1 毫秒）。故選 (A)。

Q-02-04-P02質數判定開根號上界優化（$O(\sqrt{N})$）數學與效能原理分析 效能分析

對應 單元 2.4

在 APCS 質數檢驗演算法中，欲判定正整數 $N = 100000007$ 是否為質數，下列兩種迴圈檢查範圍：

# 策略甲：檢查到 N - 1（需執行約 10^8 次）
for i in range(2, N): ...

# 策略乙：檢查到 int(N ** 0.5)（僅需執行約 10000 次）
limit = int(N ** 0.5)
for i in range(2, limit + 1): ...

策略乙將時間複雜度從 $O(N)$ 驟降為 $O(\sqrt{N})$，大幅避免超時（TLE）。下列關於此優化策略數學原理的說明何者最正確？

🎉 答對了！標準答案是 (A)
⚡ 速解

因數成對出現！若有因數必有一個 $\le \sqrt{N}$。若到 $\sqrt{N}$ 都找不到因數，後面絕不可能有！檢查次數從一億次降到一萬次，速度提升萬倍。秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 因數對稱性數學反證法：
  • 假設合數 $N = a \times b$，且不妨設 $a \le b$。
  • 若 $a > \sqrt{N}$，則因為 $b \ge a$，必有 $b > \sqrt{N}$。
  • 此時兩者相乘 $a \times b > \sqrt{N} \times \sqrt{N} = N$，與前提矛盾！
  • 因此較小的因數 $a$ 必然落在區間 $[2, \sqrt{N}]$ 之內。
  • 只要在 $[2, \lfloor\sqrt{N}\rfloor]$ 範圍內沒有找到任何能整除 $N$ 的數字，$N$ 就百分之百確定是質數！
  • 執行次數由 $10^8$ 次縮減為約 $10^4$ 次，在 1 秒時限內保證 AC。故選 (A)。

Q-02-04-L02平面歐氏幾何距離（畢氏定理開方）邏輯追蹤 計算邏輯

對應 單元 2.4

計算二維平面上兩點 $(x_1, y_1) = (0, 0)$ 與 $(x_2, y_2) = (6, 8)$ 之間的直線距離：

x1, y1 = 0, 0
x2, y2 = 6, 8

dx = x2 - x1
dy = y2 - y1
dist_sq = dx ** 2 + dy ** 2
distance = dist_sq ** 0.5

print(int(distance))

執行這段程式後，畫面上印出的直線距離整數為何？

🎉 答對了！標準答案是 (A)
⚡ 速解

畢氏定理：$dx = 6$, $dy = 8$。平方和 $6^2 + 8^2 = 36 + 64 = 100$。開根號 $\sqrt{100} = 100^{0.5} = 10$。秒選 (A) 10。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 二維歐氏距離計算鏈：
  • 距離公式：$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$。
  • 水平差與垂直差：
  • dx = 6 - 0 = 6。
  • dy = 8 - 0 = 8。
  • 平方和累加：
  • dx ** 2 = 36。
  • dy ** 2 = 64。
  • dist_sq = 36 + 64 = 100。
  • 開平方根求值：
  • distance = 100 ** 0.5 = 10.0（浮點數）。
  • int(10.0) 轉換為整數 10。印出 10。故選 (A)。
  1. 選項干擾分析：
  • (B) 14：誤將曼哈頓距離（$|dx| + |dy| = 6 + 8 = 14$）當成直線距離。
  • (C) 100：漏做了最後一步開根號運算。
