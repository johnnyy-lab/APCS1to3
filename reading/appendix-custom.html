Q-90-03-R01只改其中一筆的分數 運行追蹤

對應 附錄・自訂資料型態

Rec 把姓名和分數包成一筆。下列程式印出什麼？

class Rec:
    def __init__(self, name, score):
        self.name = name
        self.score = score

a = Rec("安", 80)
b = Rec("安", 90)
a.score = 70
print(a.score, b.score)
🎉 答對了！標準答案是 (A)
⚡ 速解

a 和 b 是兩次 Rec(...)，各有自己的分數。只改 a.score，所以印出 70 90，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • a 的分數從 80 建好，b 的分數從 90 建好。
  • a.score = 70 只改 a 這一個物件。
  • b.score 仍是 90。故選 (A)。
  1. 選項逐項診斷：
  • (A) 兩筆資料互不影響。
  • (B) 姓名相同不會讓兩筆變成同一個物件。
  • (C) 80 已經被改成 70。
  • (D) 兩個分數的位置顛倒了，而且 80 已經不在了。
  1. APCS 考場心法與常見陷阱：
  • 每寫一次 Rec(...) 就多一筆新資料。姓名、分數這些欄位值一樣，也不代表是同一筆。

Q-90-03-R02兩個名字指到同一筆 運行追蹤

對應 附錄・自訂資料型態

t = s 之後呼叫 t.add(5)。程式印出什麼？

class Rec:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def add(self, d):
        self.score += d

s = Rec("貝", 60)
t = s
t.add(5)
print(s.score, t.score)
🎉 答對了！標準答案是 (C)
⚡ 速解

t = s 沒有建立新的一筆，兩個名字看的是同一份分數，所以兩邊都變成 65，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • s 建立時分數是 60。
  • t = s 只是再取一個名字，沒有呼叫 Rec(...)。
  • t.add(5) 把這一份分數加成 65。s.score 與 t.score 看的是同一個欄位。故選 (C)。
  1. 選項逐項診斷：
  • (A) 把 t = s 誤認為複製出第二筆。
  • (B) add(5) 有執行，分數不會停在 60。
  • (C) 兩個名字看到同一次加分。
  • (D) 不存在「只有 s 加分、t 不加」的第二份資料。
  1. APCS 考場心法與常見陷阱：
  • 想要獨立的一筆，要再呼叫一次 Rec(...)。指派 t = s 只是多一個名字。

Q-90-03-D01加分沒有寫進這筆資料 測試除錯

對應 附錄・自訂資料型態

想呼叫 s.add(3) 後印出 13。現在發生 UnboundLocalError。只改 add 裡的那一行，哪一個改法會印出 13？

class Rec:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def add(self, d):
        score += d

s = Rec("德", 10)
s.add(3)
print(s.score)
🎉 答對了！標準答案是 (C)
⚡ 速解

score += d 找的是函式裡的區域變數，不是這筆資料的欄位。要改的是 self.score，秒選 (C)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • __init__ 已把 self.score 設成 10。
  • score += d 因為有賦值，score 被當成 add 的區域變數，可是右邊還沒有值，於是 UnboundLocalError。
  • 改成 self.score += d 後，10 加上 3，印出 13。故選 (C)。
  1. 選項逐項診斷：
  • (A) score = d 只建立區域變數，s.score 仍是 10。
  • (B) 函式裡那一行還是會先發生 UnboundLocalError，呼叫引數改成 13 也到不了印出。
  • (C) 加分寫回這筆資料自己的欄位。
  • (D) 欄位沒有建立，但 add 裡仍是 score += d。這一行會先發生 UnboundLocalError，程式到不了後面的 print。
  1. APCS 考場心法與常見陷阱：
  • 函式裡要改物件欄位時，左邊要寫 self.欄位。少了 self，名字就變成這個函式自己的區域變數。

Q-90-03-D02改第二筆的標籤卻動到第一筆 測試除錯

對應 附錄・自訂資料型態

想讓 b 追加「數學」之後，a.tags 仍印出 ['國文']。現在印出 ['國文', '數學']。只改建立 b 的那一行，哪一個改法符合要求？

class Rec:
    def __init__(self, name, tags):
        self.name = name
        self.tags = tags

a = Rec("恩", ["國文"])
b = Rec("恩", a.tags)
b.tags.append("數學")
print(a.tags)
🎉 答對了！標準答案是 (A)
⚡ 速解

a.tags 是同一份串列。建立 b 時要抄出一份新串列，a.tags[:] 做得到，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • b = Rec("恩", a.tags) 時，兩筆的 tags 指到同一個串列。
  • append("數學") 改的是那一份串列，所以 a.tags 也變長。
  • a.tags[:] 複製出新串列再放進 b，追加只影響 b。故選 (A)。
  1. 選項逐項診斷：
  • (A) 切片複製後，兩筆標籤分開。
  • (B) 改成對 a.tags 追加，第一筆更直接被改掉。
  • (C) b.tags 變成字串，append 會發生 AttributeError。
  • (D) 最後改印姓名，標籤串列仍然被共用，只是這一行沒印出來。
  1. APCS 考場心法與常見陷阱：
  • 欄位若是串列、字典這類可變資料，傳進新物件時傳的是同一份。要分開，就先複製欄位。

Q-90-03-P01迴圈裡建立了幾筆 效能分析

對應 附錄・自訂資料型態

這個迴圈一共執行幾次 Rec(...)？

class Rec:
    def __init__(self, name):
        self.name = name

items = []
for i in range(4):
    items.append(Rec("甲"))
items[0].name = "乙"
print([r.name for r in items])
🎉 答對了！標準答案是 (D)
⚡ 速解

range(4) 轉 4 圈，每圈都呼叫一次 Rec(...)，所以是 4 筆。印出的名字有兩種，不代表只建立 2 筆，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 迴圈建立 4 個新物件，一開始名字都是「甲」。
  • 只把第 0 筆改成「乙」。
  • 印出 ['乙', '甲', '甲', '甲']，四筆都還在。故選 (D)。
  1. 選項逐項診斷：
  • (A) 若 4 圈共用同一筆，四個名字會全部變成「乙」。印出的結果不是這樣。
  • (B) 2 是名字的種類數，不是建立次數。
  • (C) 少算了其中一圈。
  • (D) 每圈一次，共 4 次。
  1. APCS 考場心法與常見陷阱：
  • Rec(...) 寫在迴圈裡面，就會每圈各建一筆。先建一筆再在迴圈裡重複放進同一個物件，改一筆才會改到全部。

Q-90-03-P02add 裡的加分執行幾次 效能分析

對應 附錄・自訂資料型態

self.v += 1 這一行一共執行幾次？

class Rec:
    def __init__(self, v):
        self.v = v

    def inc(self):
        self.v += 1

a = Rec(0)
for _ in range(5):
    a.inc()
print(a.v)
🎉 答對了！標準答案是 (B)
⚡ 速解

inc 被呼叫 5 次，那一行就執行 5 次，最後 a.v 也是 5，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • __init__ 用 self.v = v 把值設成 0，這一行不是 +=。
  • 迴圈呼叫 inc 五次，每次都執行 self.v += 1。
  • 最後印出 5。故選 (B)。
  1. 選項逐項診斷：
  • (A) 迴圈不是只呼叫一次。
  • (B) range(5) 正好 5 次加分。
  • (C) 6 把 __init__ 的第一次設定也算進 +=。題目問的是 self.v += 1 這一行。
  • (D) print(a.v) 印出 5，加分確實有執行。
  1. APCS 考場心法與常見陷阱：
  • 設定 self.v = v 與加 self.v += 1 是兩行。題目點名哪一行，就只數那一行。

Q-90-03-L01函式從很多筆裡挑出誰 計算邏輯

對應 附錄・自訂資料型態

f 接收至少一筆 Rec。高分 是 90 分、低分 是 70 分時，f 回傳 "高分"。它在做什麼？

class Rec:
    def __init__(self, name, score):
        self.name = name
        self.score = score

def f(records):
    best = records[0]
    for r in records:
        if r.score > best.score:
            best = r
    return best.name
🎉 答對了！標準答案是 (A)
⚡ 速解

迴圈只在分數更大時換掉 best，最後回傳的是姓名。90 比 70 大，所以回傳 "高分"，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • best 先指到第一筆。
  • 後面每一筆只和目前最高分比，更大才換人。
  • 回傳的是 best.name，不是分數合計，也不是筆數。故選 (A)。
  1. 選項逐項診斷：
  • (A) 比較的是 score，交出去的是 name。
  • (B) 函式裡沒有做加法。
  • (C) 沒有依姓名排序。若第一筆分數最高，就不會因為姓名順序而換人。
  • (D) 回傳的是字串姓名。題幹的結果是 "高分"，不是 2。
  1. APCS 考場心法與常見陷阱：
  • 分數相同時，> 不會換人，所以會留下較早的那一筆。題目若沒有說同分怎麼辦，不要把它說成一定換到後面那筆。

Q-90-03-L02兩筆欄位各自相加 計算邏輯

對應 附錄・自訂資料型態

p 是 (1, 2) 這一筆、q 是 (3, 4) 這一筆時，f(p, q) 的 x 是 4、y 是 6，而且 p、q 自己的欄位不變。f 在做什麼？

class Rec:
    def __init__(self, x, y):
        self.x = x
        self.y = y

def f(p, q):
    return Rec(p.x + q.x, p.y + q.y)
🎉 答對了！標準答案是 (D)
⚡ 速解

1 + 3 = 4、2 + 4 = 6，而且回傳的是新的 Rec。p 仍是 (1, 2)，秒選 (D)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 新物件的 x 取兩筆 x 相加，y 取兩筆 y 相加。
  • p.x、p.y、q.x、q.y 都只被讀取，沒有被指派。
  • 所以舊的兩筆維持原樣。故選 (D)。
  1. 選項逐項診斷：
  • (A) p 的欄位沒有改成 q 的欄位。
  • (B) 回傳的是一筆新資料，不是誰比較大。
  • (C) 距離不會是 x 相加、y 再相加。(1, 2) 與 (3, 4) 的直線距離也不是 4 和 6 這兩個欄位。
  • (D) 同名欄位相加後放進新物件。
  1. APCS 考場心法與常見陷阱：
  • 回傳 Rec(...) 就是交出新的一筆。函式裡沒有寫 p.x = ...，呼叫後的舊資料就不會變。

🎉 答對了！標準答案是 (B)
⚡ 速解

找到相同姓名就立刻回傳那一筆的分數。整圈都沒有，才回傳 None，秒選 (B)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • 逐筆比較 r.name。
  • 「乙」對上時回傳 90，後面的資料不再看。
  • 「丙」沒有任何一筆符合，迴圈結束後回傳 None。故選 (B)。
  1. 選項逐項診斷：
  • (A) 串列沒有刪除任何一筆。
  • (B) 找到就交出分數，找不到有明確的回傳值。
  • (C) 回傳的是數字或 None，不是姓名字串。
  • (D) 它沒有比較誰的分數比較高。若「甲」排在前面且被指定尋找，就不會改回最高分。
  1. APCS 考場心法與常見陷阱：
  • return 寫在迴圈裡時，找到第一筆就結束。同名若出現兩次，後面的那一次不會被看到。

Q-90-03-L06兩個欄位對調後做成新的一筆 計算邏輯

對應 附錄・自訂資料型態

p 是 (2, 5) 這一筆時，f(p) 的 x 是 5、y 是 2，而且 p 自己仍是 (2, 5)。f 在做什麼？

class Rec:
    def __init__(self, x, y):
        self.x = x
        self.y = y

def f(p):
    return Rec(p.y, p.x)
🎉 答對了！標準答案是 (A)
⚡ 速解

新物件的第一個欄位放原來的 y，第二個欄位放原來的 x。p 沒有被指派，秒選 (A)。

🔍 深度詳解（慢動作拆解與常見陷阱）
  1. 慢動作：
  • Rec(p.y, p.x) 用 5 當新的 x、用 2 當新的 y。
  • p.x 和 p.y 都只被讀取。
  • 舊的一筆仍是 (2, 5)。故選 (A)。
  1. 選項逐項診斷：
  • (A) 新資料的兩個欄位互換，舊資料不變。
  • (B) 相加會得到一個數字，不是 x = 5、y = 2 的新資料。
  • (C) 函式裡沒有寫 p.x = ... 或 p.y = ...。
  • (D) 新資料仍有兩個欄位，y 沒有被丟掉。
  1. APCS 考場心法與常見陷阱：
  • 對調欄位若要保留原件，就要做出新的一筆。直接交換 p.x 和 p.y 會改到原來的物件。
