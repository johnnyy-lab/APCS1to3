第 1 題 程式運行追蹤 第 1 章

先指定 a、b，再把 b 寫進 a，最後用當時的 a 去改 b。程式印出什麼？

a = 2
b = 5
a = b
b = a + 1
print(a, b)
  1. (A) 5 6
  2. (B) 2 6
  3. (C) 5 3
  4. (D) 2 3

答案 (A)

⚡ 速解

a = b 之後 a 已是 5。下一行用的是這個新的 5，所以 b 變成 6。印出 5 6，選 (A)。

🔍 深度詳解

  1. 慢動作：
  • 一開始 a 是 2、b 是 5。
  • a = b 把 5 寫進 a，b 仍是 5。
  • b = a + 1 讀到的 a 已是 5，所以 b 變成 6。
  • print(a, b) 印出 5 6。
  1. 選項逐項診斷：
  • (A) 兩次指定都用到新值，是 5 6。
  • (B) 把 a 留在 2，忽略了 a = b。
  • (C) 用一開始的 2 去算 2 + 1，但那時 a 已經改成 5。
  • (D) 兩個都停在舊值附近，沒有跟著指定走。
  1. 考場心法：
  • 等號右邊先算完，再寫進左邊。算下一行時，上一行的指定已經生效。

第 2 題 程式填空 第 2 章

空格填入一段運算式，使程式印出 7。

n = 23
print(______)
  1. (A) n / 5 + n % 5
  2. (B) n // 5 + n % 5
  3. (C) n // 5 * n % 5
  4. (D) n % 5 // n

答案 (B)

⚡ 速解

23 除以 5，整數商是 4、餘數是 3，4 加 3 才是 7。要的是 // 不是 /，選 (B)。

🔍 深度詳解

  1. 慢動作：
  • 23 // 5 是 4，23 % 5 是 3，相加是 7。
  • / 得到的是浮點數 4.6，4.6 加 3 是 7.6，不是 7。
  1. 選項逐項診斷：
  • (A) n / 5 + n % 5 印出 7.6。
  • (B) 整數商加餘數，印出 7。
  • (C) //、*、% 優先順序相同，由左算到右：(23 // 5 * 23) % 5 是 2。
  • (D) (23 % 5) // 23 是 3 // 23，結果是 0。
  1. 考場心法：
  • 題目要整數結果時，先看有沒有用 /。*、//、% 同一層，不要先把 % 抓去跟右邊結合。

第 3 題 程式測試與除錯 第 5 章

這段程式目前無法執行。它想做到：x 是偶數就印 偶，否則印 奇。只改 if 那一行。改完後，x 換成 0 或 7 也要印對。

x = 4
if x = 2:
    print("偶")
else:
    print("奇")
  1. (A) if x = 0:
  2. (B) if x / 2:
  3. (C) if x % 2 == 0:
  4. (D) if x % 2 = 0:

答案 (C)

⚡ 速解

= 是指定，不能寫在 if 後面。偶數是除以 2 的餘數為 0，選 (C)。

🔍 深度詳解

  1. 慢動作：
  • 原程式的 x = 2 是指定，不是比較，語法不成立。
  • x % 2 == 0 在 x 為 0、4 時成立，印 偶；x 為 7 時不成立，印 奇。
  1. 選項逐項診斷：
  • (A) 還是用 = 做指定，一樣無法執行。
  • (B) x / 2 在 x 為 4 時是 2.0，被當成成立；但 x 為 7 時是 1.5，也成立，奇數會印成 偶。x 為 0 時是 0.0，反而不成立。
  • (C) 用餘數判斷偶數，0、4、7 都印對。
  • (D) x % 2 = 0 仍是指定，無法執行。
  1. 考場心法：
  • 比較要用 ==。一個非零的數放在 if 後面會被當成成立，不能拿來代替「是不是偶數」。

第 4 題 程式效能分析 第 6 章

n = n + 1 這一行執行幾次？

n = 0
for i in range(1, 7):
    if i % 2 == 0:
        n = n + 1
print(n)
  1. (A) 1
  2. (B) 2
  3. (C) 6
  4. (D) 3

答案 (D)

⚡ 速解

range(1, 7) 走出 1 到 6。其中偶數是 2、4、6，那一行跑 3 次，選 (D)。

🔍 深度詳解

  1. 慢動作：
  • 迴圈變數依序是 1、2、3、4、5、6，共 6 圈。
  • 只有 2、4、6 進得了 if，所以 n = n + 1 執行 3 次。
  1. 選項逐項診斷：
  • (A) 只算到第一個偶數就停。
  • (B) 少算了 6。
  • (C) 把整個迴圈的圈數當成那一行的次數。
  • (D) 三個偶數各進一次，是 3。
  1. 考場心法：
  • 效能題問的是某一行跑幾次。外層圈數和 if 裡面的次數要分開數。這裡最後印出的 3 剛好等於次數，換一組範圍時不一定還一樣。

第 5 題 解析計算邏輯 第 3 章

把 a、b 換成別的數，這段程式仍然在算同一件事。它在算什麼？

a = 8
b = 3
print(abs(a - b))
  1. (A) a 與 b 相差多少，結果不會是負的
  2. (B) a 與 b 相加
  3. (C) a 與 b 相乘
  4. (D) a 與 b 之中比較小的那個

答案 (A)

⚡ 速解

abs(a - b) 是兩數差的絕對值。8 和 3 得到 5；換成 1 和 9 得到 8。只有 (A) 兩次都對。

🔍 深度詳解

  1. 慢動作：
  • a - b 是 5，abs(5) 仍是 5。
  • 若 a 是 1、b 是 9，a - b 是 -8，abs 把它變成 8。
  1. 選項逐項診斷：
  • (A) 兩組數都得到差的絕對值，5 和 8。
  • (B) 兩數相加是 11 和 10，都不是程式印出的值。
  • (C) 兩數相乘是 24 和 9，也不符合。
  • (D) 較小的那個是 3 和 1，不符合。
  1. 考場心法：
  • 邏輯題不能只對一組數字。先用題幹的數字淘汰，再用另一組數字確認剩下的那句。

第 6 題 程式運行追蹤 第 6 章

這個迴圈每次把 x 加進 s，再把 x 減 4。程式印出什麼？

x = 10
s = 0
while x > 0:
    s = s + x
    x = x - 4
print(s)
  1. (A) 10
  2. (B) 16
  3. (C) 18
  4. (D) 22

答案 (C)

⚡ 速解

x 走 10、6、2，然後變成 -2 就離開。s 是 10 + 6 + 2，印出 18，選 (C)。

🔍 深度詳解

  1. 慢動作：
  • x 為 10：s 變成 10，x 變成 6。
  • x 為 6：s 變成 16，x 變成 2。
  • x 為 2：s 變成 18，x 變成 -2。
  • -2 已經不大於 0，迴圈停止，印出 18。
  1. 選項逐項診斷：
  • (A) 只加了第一次的 10。
  • (B) 停在 10 + 6，少加了 2。
  • (C) 三次都加完，是 18。
  • (D) 多加了一次不在這條路上的 4。
  1. 考場心法：
  • while 先看條件再進迴圈。減完之後要回到上面重看條件，不要把已經不大於 0 的值也加進去。

第 7 題 程式填空 第 5 章

空格填入一段程式，使它在分數低於 60 時把 ok 改成 False，並印出 False。

score = 59
ok = True
______
print(ok)
  1. (A) if score < 60: ok = True
  2. (B) if score < 60: ok = False
  3. (C) if score > 60: ok = False
  4. (D) if score == 60: ok = False

答案 (B)

⚡ 速解

59 低於 60，條件要寫 <，而且進了之後要把 ok 改成 False。選 (B)。

🔍 深度詳解

  1. 慢動作：
  • 一開始 ok 是 True。
  • score < 60 成立，把 ok 改成 False，印出 False。
  1. 選項逐項診斷：
  • (A) 條件成立，但寫回的仍是 True，印出 True。
  • (B) 條件與指定都對，印出 False。
  • (C) 59 並沒有大於 60，ok 維持 True。
  • (D) 59 也不等於 60，ok 維持 True。
  1. 考場心法：
  • 填空要同時看條件方向和寫進去的值。方向對了、寫錯值，結果仍不對。

第 8 題 程式測試與除錯 第 6 章

這段程式想逐行印出 1、2、3。現在印出的是 0、1、2。只改 for 那一行。

for i in range(3):
    print(i)
  1. (A) for i in range(3):
  2. (B) for i in range(0, 3):
  3. (C) for i in range(2, 5):
  4. (D) for i in range(1, 4):

答案 (D)

⚡ 速解

range(3) 從 0 起算、不含 3。要 1、2、3，就從 1 起算、停在 4 之前。選 (D)。

🔍 深度詳解

  1. 慢動作：
  • range(1, 4) 走出 1、2、3，每圈印一行。
  1. 選項逐項診斷：
  • (A) 和原來相同，仍是 0、1、2。
  • (B) range(0, 3) 也是 0、1、2。
  • (C) range(2, 5) 是 2、3、4。
  • (D) range(1, 4) 是 1、2、3。
  1. 考場心法：
  • range 含起點、不含終點。只寫一個數時，起點是 0。

第 9 題 程式效能分析 第 8 章

執行 a.pop(0) 時，還留在串列裡、並且被往前挪一格的元素有幾個？

a = [8, 1, 6, 4, 9]
a.pop(0)
  1. (A) 4
  2. (B) 5
  3. (C) 1
  4. (D) 0

答案 (A)

⚡ 速解

拿走最前面的 8 之後，剩下的 1、6、4、9 各往前一格，共 4 個。選 (A)。

🔍 深度詳解

  1. 慢動作：
  • 原串列有 5 個元素。
  • pop(0) 刪掉索引 0。它後面的 4 個元素都要補上前面空出的位置。
  1. 選項逐項診斷：
  • (A) 被挪動的是刪掉之後還留著的 4 個。
  • (B) 把原來的長度算進去，包含已經被拿走的那個。
  • (C) 只算被拿走的那一個，它是離開，不是往前挪。
  • (D) 以為刪掉一格就沒有元素要移動。
  1. 考場心法：
  • 從串列最前面刪，後面每一格都要往前補。次數是「刪掉之後剩下幾個」，不是整個長度。

第 10 題 解析計算邏輯 第 7 章

把 s 換成別的字串，這段程式仍然在做同一件事。它在做什麼？

s = "abcd"
print(s[::-1])
  1. (A) 把字串裡的英文字母改成大寫
  2. (B) 只留下第一個字
  3. (C) 把字串前後對調
  4. (D) 刪掉最後一個字

答案 (C)

⚡ 速解

[::-1] 從後面走到前面。"abcd" 變成 "dcba"；換成 "py" 會變成 "yp"。選 (C)。

🔍 深度詳解

  1. 慢動作：
  • 步長是 -1，起點預設在最後一格，所以順序倒過來。
  • "abcd" 印出 dcba。
  1. 選項逐項診斷：
  • (A) 大寫會是 ABCD，而且 "py" 會變成 PY，都不是這段程式。
  • (B) 第一個字是 a；換成 "py" 會是 p。程式印出的是整串倒過來。
  • (C) 兩組字串都是前後對調。
  • (D) 刪掉最後一個字會剩下 abc；"py" 會剩下 p。
  1. 考場心法：
  • 切片三個數是起點、終點、步長。步長 -1 而且兩端都省略，就是整串倒過來。

第 11 題 程式運行追蹤 第 7 章

字串重複之後，再接上 s 的第一個字。程式印出什麼？

s = "py"
print("py" * 2 + s[0])
  1. (A) py
  2. (B) pypy
  3. (C) pypy2
  4. (D) pypyp

答案 (D)

⚡ 速解

"py" * 2 是 pypy，s[0] 是 p，接起來是 pypyp。選 (D)。

🔍 深度詳解

  1. 慢動作：
  • 字串乘上整數是重複，不是做算術。"py" * 2 得到 pypy。
  • s[0] 是第一個字 p。
  • 兩者用 + 接成 pypyp。
  1. 選項逐項診斷：
  • (A) 只留下原本的 s。
  • (B) 重複做完就停，沒有再接 s[0]。
  • (C) 把後面的 2 當成文字接上去。
  • (D) 重複之後再接一個 p，是 pypyp。
  1. 考場心法：
  • 字串的 * 在重複，+ 在串接。索引從 0 開始。

第 12 題 程式填空 第 8 章

空格填入一段程式，使它把奇數收集起來，印出 [1, 3]。

a = [1, 2, 3, 4]
b = []
for x in a:
    if x % 2 == 1:
        ______
print(b)
  1. (A) a.append(x)
  2. (B) b.append(x)
  3. (C) b = x
  4. (D) b.append(a)

答案 (B)

⚡ 速解

新的串列是 b。奇數 1 和 3 要放進 b，選 (B)。

🔍 深度詳解

  1. 慢動作：
  • x 依序是 1、2、3、4。
  • 1 和 3 是奇數，b.append(x) 之後 b 是 [1, 3]。
  1. 選項逐項診斷：
  • (A) 把奇數又加回正在走訪的 a，串列會愈走愈長，停不下來。
  • (B) 加進另一條串列 b，印出 [1, 3]。
  • (C) b = x 每次把整份 b 換成一個數，最後 b 是 3，不是串列。
  • (D) 加進去的是整份 a，會印出 [[1, 2, 3, 4], [1, 2, 3, 4]]。
  1. 考場心法：
  • for x in a 還在走的時候，不要對 a 做 append。收集結果要用另一條串列。

第 13 題 程式測試與除錯 第 9 章

這段程式想把第一列（橫向那一列，兩個數是 1 和 2）加總，結果應為 3。現在印出的是 4。只改加總那一行。

g = [[1, 2], [3, 4]]
s = 0
for c in range(2):
    s = s + g[c][0]
print(s)
  1. (A) s = s + g[0][c]
  2. (B) s = s + g[c][1]
  3. (C) s = s + g[1][c]
  4. (D) s = s + g[c][c]

答案 (A)

⚡ 速解

第一列要固定列號 0，讓行號 c 去走。g[0][c] 加到的是 1 和 2。選 (A)。

🔍 深度詳解

  1. 慢動作：
  • 原程式的 g[c][0] 走的是每一列的第 0 行：1 加 3，得到 4。
  • 改成 g[0][c] 之後，固定在第 0 列，加到 1 和 2，得到 3。
  1. 選項逐項診斷：
  • (A) 第一列的兩格，和是 3。
  • (B) g[c][1] 是每一列的第 1 行：2 加 4，得到 6。
  • (C) g[1][c] 是第二列：3 加 4，得到 7。
  • (D) g[c][c] 是 1 和 4，得到 5。
  1. 考場心法：
  • g[列][行]。題目說橫向的一列時，列號固定，變的是行號。

第 14 題 程式效能分析 第 11 章

從 f(3) 這一次開始算，函式 f 總共被呼叫幾次？含 f(3) 自己。

def f(n):
    if n == 0:
        return 0
    return n + f(n - 1)

print(f(3))
  1. (A) 3
  2. (B) 6
  3. (C) 4
  4. (D) 1

答案 (C)

⚡ 速解

呼叫鏈是 f(3)、f(2)、f(1)、f(0)，共 4 次。印出的 6 是回傳值，不是次數。選 (C)。

🔍 深度詳解

  1. 慢動作：
  • f(3) 要先呼叫 f(2)。
  • f(2) 要先呼叫 f(1)，f(1) 再呼叫 f(0)。
  • f(0) 直接回傳 0，不再往下。四次呼叫之後才開始相加，回傳值是 6。
  1. 選項逐項診斷：
  • (A) 只算了引數 3，沒有把往下的呼叫算進去。
  • (B) 6 是 3 + 2 + 1 + 0 的回傳值。
  • (C) 含自己在內一共 4 次。
  • (D) 只算了最後停住的那一次。
  1. 考場心法：
  • 問「呼叫幾次」時，沿著每一次 f(...) 畫一格，不要把 print 印出的回傳值當成次數。

第 15 題 解析計算邏輯 第 9 章

換成別的表格，這段程式仍然在算同一件事。它在算什麼？

g = [[1, 2], [3, 4], [5, 6]]
s = 0
for row in g:
    s = s + row[0]
print(s)
  1. (A) 每一列的兩個數都加進總和
  2. (B) 每一列最左邊那個數相加
  3. (C) 每一列最右邊那個數相加
  4. (D) 格子的個數

答案 (B)

⚡ 速解

row[0] 是每一列的第一格。1、3、5 相加是 9。換成 [[2, 9], [8, 3]] 會得到 10，仍是每一列最左邊相加。選 (B)。

🔍 深度詳解

  1. 慢動作：
  • 三列的第 0 格是 1、3、5，總和 9。
  • 另一張表 [[2, 9], [8, 3]] 的第 0 格是 2 和 8，總和 10。
  1. 選項逐項診斷：
  • (A) 全部格子相加，兩張表分別是 21 和 22。
  • (B) 兩張表都是每一列最左邊相加，9 和 10。
  • (C) 最右邊相加是 12 和 12。
  • (D) 格子個數是 6 和 4。
  1. 考場心法：
  • for row in g 一次拿一列。row[0] 固定是那一列的第一格，不是整列，也不是最後一格。

第 16 題 程式運行追蹤 第 10 章

get 找不到鍵時會交回預設值，但不會因此新增那個鍵。程式印出什麼？

d = {"甲": 1}
d["甲"] = d.get("乙", 0) + 3
print(d["甲"], d.get("乙"))
  1. (A) 4 None
  2. (B) 3 0
  3. (C) 1 None
  4. (D) 3 None

答案 (D)

⚡ 速解

字典裡沒有「乙」，get 交回 0，但沒有把「乙」放進去。d["甲"] 變成 0 + 3，後面再 get 一次仍是 None。選 (D)。

🔍 深度詳解

  1. 慢動作：
  • d.get("乙", 0) 因為沒有這個鍵，交回 0。字典仍只有「甲」。
  • d["甲"] 被改成 3。
  • 印出時 d["甲"] 是 3；d.get("乙") 沒有給預設值，找不到就交回 None。
  1. 選項逐項診斷：
  • (A) 把原來的 1 再加 3，忽略了指定的右邊是 0 + 3。
  • (B) 以為 get 的預設值 0 會留在字典裡。
  • (C) 以為指定沒有改到「甲」。

第 23 題 程式測試與除錯 第 12 章

這個函式想在已經由小到大排好的串列裡找 target。找到就回傳位置，找不到回傳 -1。現在 find([1, 3, 5, 7], 7) 會停不下來。只改 lo = mid 那一行。

def find(a, target):
    lo = 0
    hi = len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid
        else:
            hi = mid - 1
    return -1
  1. (A) lo = mid
  2. (B) lo = mid + 1
  3. (C) lo = mid - 1
  4. (D) hi = mid

答案 (B)

⚡ 速解

目標比中間大時，左界要移到中間的右邊一格。寫成 lo = mid 時，中間那一格還留在範圍裡，下一圈可能停在同一個位置。選 (B)。

🔍 深度詳解

  1. 慢動作：
  • 找 7 時，第一次中間是 3，比 7 小，lo = mid 使 lo 變成 1。
  • 下一圈中間是 5，仍比 7 小，lo 變成 2。
  • 再下一圈中間還是索引 2 的 5，lo 又被設成 2，範圍不再縮小。
  • 改成 lo = mid + 1 之後，找 1、3、5、7 會回傳 0、1、2、3；找 0、6、8 會回傳 -1。
  1. 選項逐項診斷：
  • (A) 和原來相同，找 7 時停不下來。
  • (B) 左界排除已經看過的中間，找得到的回傳位置，找不到的回傳 -1。
  • (C) lo = mid - 1 可能把左界往回推，找 5 時也會停不下來。
  • (D) 目標比中間大時卻去改右界，找 7 時 lo 和 hi 會停在同一組值上，一樣停不下來。
  1. 考場心法：
  • 二分搜尋縮小範圍時，看過的中間那一格不能留在下一圈。否則左界或右界沒有前進，迴圈就不會結束。

  3. (C) [7, 1]
  4. (D) []

2 是偶數，留下。7 和 1 是奇數，放進去就立刻被 pop() 拿走。最後只剩 [2]。選 (A)。

  2. (B) 做出新的一筆，並把 a 的 x 改成 0
  3. (C) 做出新的一筆，x 是原來的 x 加上 dx；a 維持原樣
  4. (D) 讓 b 和 a 指到同一筆資料

答案 (C)

⚡ 速解

moved 回傳的是另一個新的 Rec，沒有寫進 a.x。4 加 3 得到新的 7，原來的 4 還在。印出 4 7。選 (C)。

🔍 深度詳解

  1. 慢動作：
  • a.x 是 4。Rec(self.x + dx) 做出 x 為 7 的新物件，交給 b。
  • a 沒有被指定新的欄位，所以印出 4 7。
  • 若起點改成 1、dx 改成 10，會印出 1 11。a 仍然不變。
  1. 選項逐項診斷：
  • (A) 若連 a 一起改，兩次會印出 7 7 和 11 11。
  • (B) 程式沒有把 a.x 寫成 0，也不會印出 0 7。
  • (C) 新的一筆帶著加過的 x，舊的一筆不變。兩組數都符合。
  • (D) 若兩個名字指到同一筆，印出的兩個數會相同。這裡是 4 7。
  1. 考場心法：
  • 方法裡回傳 Rec(...) 就是在做新的一筆。沒有出現 self.x = ...，原來那一筆就不會改。
