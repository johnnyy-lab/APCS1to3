Q-09-01-R01先改一格再讀右下角 運行追蹤

答案 (B)

⚡ 速解

先改 grid[2][1]，它變成 grid[0][0] 的 1。右下角 grid[-1][-1] 仍是 9，沒有被這一格連帶改掉。下一行把 9 寫進 grid[0][0]。印出的是新的第 0 列 [9, 2, 3]，以及剛才寫入的 1，秒選 (B)。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 慢動作執行步驟追蹤：
  • 起始網格是 3 列 3 行。第 0 列 [1, 2, 3]，第 1 列 [4, 5, 6]，第 2 列 [7, 8, 9]。
  • grid[2][1] = grid[0][0]：右邊先讀到 1，寫進第 2 列第 1 行。第 2 列變成 [7, 1, 9]。
  • 這一筆只改中間那一格。右下角 grid[2][2] 仍是 9。
  • grid[-1] 就是最後一列，grid[-1][-1] 就是該列最後一格，讀到 9。
  • grid[0][0] = 9 之後，第 0 列變成 [9, 2, 3]。第 2 列第 1 行維持 1。
  • print(grid[0], grid[2][1]) 印出 [9, 2, 3] 1。故選 (B)。
  1. 選項逐項診斷：
  • (A) 兩次指定都沒算進去，第 0 列與 grid[2][1] 都留在舊值。
  • (B) 兩次指定的先後與「只改一格」都對上。
  • (C) 右下角抄回左上角是對的，但漏掉 grid[2][1] 已經改成 1。
  • (D) 把 grid[2][0] 的 7 誤當成寫進左上角的值。
  1. APCS 考場心法與常見陷阱：
  • grid[r][c] = ... 只換那一格，同一列的其他格、其他列都不動。
  • 負索引 -1 是該維度的最後一項。列、行可以各自用 -1，寫成 grid[-1][-1]。

Q-09-01-D01右下角的列數與行數寫反 測試除錯

答案 (C)

⚡ 速解

這張網格是 3 列 4 行。原程式把 len(grid[0]) 拿去當列索引，列索引 3 已經越界。列數要用 len(grid)，行數要用 len(grid[0])，右下角是 grid[2][3]，也就是 12，秒選 (C)。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 錯誤點：
  • len(grid) 是 3，len(grid[0]) 是 4。
  • 原式先用 4 減 1 當列、再用 3 減 1 當行，變成 grid[3][2]。列索引只到 2，所以發生 IndexError: list index out of range。
  • 右下角的正確索引是最後一列、最後一行：grid[3 - 1][4 - 1]，即 grid[2][3]，值是 12。
  1. 選項逐項診斷：
  • (A) grid[4][3] 兩個索引都越界，仍然是 IndexError。
  • (B) grid[-1][0] 是最後一列的第 0 行，印出 9，不是右下角。
  • (C) 列、行的 len 放回正確位置，印出 12。
  • (D) grid[0][-1] 是第 0 列的最後一格，印出 4。
  1. APCS 考場心法與常見陷阱：
  • 不是方陣時，列數與行數不能互換。先寫下行數 C = len(grid[0])、列數 R = len(grid)，再寫 grid[R - 1][C - 1]。

Q-09-01-D02空網格不能直接量第一列 測試除錯

答案 (B)

⚡ 速解

空串列沒有第 0 列，直接 len(grid[0]) 會 IndexError。要先看網格有沒有列：有列才量 len(grid[0])，沒有列就給 0。這就是 len(grid[0]) if grid else 0，秒選 (B)。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 兩種測資：
  • grid = [] 時，grid[0] 不存在。原程式發生 IndexError: list index out of range。
  • 有資料時，第一列 [1, 2, 3] 的長度是 3，這才是寬度。外層 len(grid) 此時是 2，那是列數，不是寬度。
  • C = len(grid[0]) if grid else 0：空網格走 else，印出 0；有資料時條件為真，印出 3。
  1. 選項逐項診斷：
  • (A) 空網格恰好印出 0，但有資料時印出列數 2，不是寬度 3。
  • (B) 兩種測資分別印出 0 與 3。
  • (C) 與原程式相同，空網格仍然當掉。
  • (D) 有資料時 len(grid[-1]) 也能得到 3，可是空網格會去算 else 的 len(grid[0])，一樣當掉。
  1. APCS 考場心法與常見陷阱：
  • len(grid[0]) 的前提是至少有一列。空網格要先擋下來。
  • 三元運算的 else 仍會在條件為假時執行。else 裡面若再寫 grid[0]，空網格還是會爆。

Q-09-02-R01讀入列數後逐列解包印出 運行追蹤

答案 (B)

⚡ 速解

第一行被讀成列數 2、行數 3。迴圈用的是 R，所以再讀兩列，不會去讀第三列。print(*row) 把一列的數字拆開，用空格隔開後印成一行。兩行是 10 20 30 與 40 50 60，秒選 (B)。

  • input() 先讀到 "2 3"。split() 得到 ["2", "3"]，轉成整數後 R 是 2、C 是 3。

  1. 選項逐項診斷：
  • (A) 這是 print(row) 的樣子，中括號和逗號還在。
  • (B) 表頭沒有被重印，兩列都解包成功。
  • (C) 把已經用掉的第一行又印了一次。
  • (D) 若迴圈寫成 range(C) 才會多讀一列而發生 EOFError。這份程式用的是 range(R)。
  1. APCS 考場心法與常見陷阱：
  • 第一行的兩個數，第一個才是接下來要讀的列數。
  • 交給評分程式的輸出不要帶中括號。一列用 print(*row)，不要 print(row) 或 print(grid)。

外層要跑 R 次，每次把一整列轉成整數。第 1 列第 2 行是 6，加 1 得到 7。寫法是 [[int(x) for x in input().split()] for _ in range(R)]，秒選 (D)。

Q-09-09-L02先整除再乘鄰居數 計算邏輯

答案 (A)

⚡ 速解

25 // 10 是 2，三個鄰居共 6。若先乘 3 得 75 再整除，得到 7。差在截斷的時機，秒選 (A)。

🔍 深度詳解（點擊展開慢動作拆解與常見陷阱）
  1. 這兩個式子：
  • 左邊 25 // 10 * 3 是 2 乘 3，得 6。自己留下 25 - 6 = 19。
  • 右邊 (25 * 3) // 10 是 75 // 10，得 7。
  • 擴散規則是每個鄰居各收同一份 P // k，用的是左邊。
  1. 選項逐項診斷：
  • (A) 鄰居數改成 0 時，左邊是 0，不會丟出例外。有的數字兩式碰巧相同，例如 P 小於 k 時兩邊都是 0。式子本身仍是先整除、再乘鄰居數；這一題的 6 與 7 說明兩式不是永遠相同。
  • (B) 這一題已經印出 6 與 7。
  • (C) 總流出是 6，不是 25。這一格留下 19。
  • (D) 25 // 10 * 0 的結果是 0，程式照常做完。
  1. APCS 考場心法與常見陷阱：
  • 先算 flow = P // k，再對每個合法鄰居送出這一份。不要先用鄰居數乘人口再整除。
  • 合法鄰居不含荒地，也不含表外。鄰居數是 0 時，總流出就是 0。
