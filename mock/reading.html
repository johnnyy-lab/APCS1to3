第 23 題 程式測試與除錯 第 12 章

這個函式想在已經由小到大排好的串列裡找 target。找到就回傳位置，找不到回傳 -1。現在 find([1, 3, 5, 7], 7) 會停不下來。只改 lo = mid 那一行。

def find(a, target):
    lo = 0
    hi = len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid
        else:
            hi = mid - 1
    return -1
